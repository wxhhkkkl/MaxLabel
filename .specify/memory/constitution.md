# MaxLabel 项目宪法

MaxLabel 是桌面端条码标签设计打印软件（Electron + React + Fabric.js），
代码位于 `app/`，按 `main` / `preload` / `renderer` / `shared` 分层。
本宪法是本仓库最高效力的工程约定；与其它文档冲突时，以本宪法为准。

## Core Principles

### I. 测试先行（TDD，不可协商）

先写测试，再写实现。每一段新功能、缺陷修复或重构 MUST 遵循以下顺序：

1. 先写表达预期行为的测试；
2. 运行并确认它**失败**，且失败原因正确（不是拼写、导入或环境错误）；
3. 再写实现，直到测试通过；
4. 在重构前保持测试全绿；红-绿-重构循环 MUST 严格遵守。

MUST NOT 采用「先实现、通过后再补测试」的方式交付。事后补写的测试无法证明它能
捕获回归——因为它们从未见过失败。

测试类型（单元 / 契约 / 集成）与深度由具体变更决定，但「先测试后实现」的顺序
不可协商。确实无法自动化验证的行为，MUST 显式记录人工验证步骤与预期结果，并在
交付说明中注明未自动化验证的部分。

**Rationale**：本项目涉及打印几何、条码编码、数据源推进、文档持久化等一旦出错
就会产生错误标签或数据丢失的领域。测试先行是唯一能在改动前锁定既有行为的机制。

### II. 先澄清，不猜测（Clarify Before Change）

任何重大重构或范围变更之前，MUST 先澄清，MUST NOT 猜测。

满足任一条件即触发澄清：

- 改动会触及多于一个层（`main` / `preload` / `renderer` / `shared`）；
- 改动会改变既有的数据模型、IPC 契约、打印流水线或持久化格式；
- 存在多于一种合理解释，且不同解释导致不同的实现与验收方式；
- 缺少做出决定所必需的外部信息（需求、凭据、第三方能力、业务规则）。

澄清方式：把疑问显式提出来，附候选项与各自影响。**允许停下来提问**；不允许在
不确定的情况下静默选一种做法然后继续。

**Rationale**：本仓库的多数返工来自「对既有能力的错误假设」——例如假定某个
IPC 通道、字段或共享模块存在，而它实际不存在。这类错误越晚暴露，修复成本越高。

### III. 巨大架构变更先确认（Confirm Large Architecture Changes）

涉及「巨大架构变更」时，MUST 在动手前取得项目所有者的明确确认。

巨大架构变更包括但不限于：

- 引入或替换运行时/框架/数据库/云服务，或新增独立进程、服务端、部署单元；
- 改变进程边界或依赖方向（例如让协议适配器重新解析数据源、让渲染层绕过
  `shared/` 维护第二套几何规则）；
- 改变核心数据模型、模板/文档格式、IPC 契约或打印计划（`PrintPlan`）的语义；
- 影响已发布版本的用户数据、授权、升级或回滚方案；
- 一次性删除或迁移大量既有代码、测试、文档（例如仓库目录级清理）。

确认时必须提供：候选方案、各方案的影响与代价、可逆性/回滚方式、以及对现有
测试与发布的影响。MUST NOT 在未确认的情况下执行「先做了再说」的架构级改动。

**Rationale**：架构决策的影响面通常跨多个模块并作用于已发布版本；一旦方向选错，
回滚成本远高于一次澄清。

## 适用范围与执行

- 适用于 `app/` 下的全部代码、测试、脚本与文档；除非另有明确说明，也适用于
  本仓库新增的目录与文件。
- 每次变更都必须能回答：预期行为是什么？哪个测试先失败？是否改变了架构边界？
  如果需要澄清或确认，是否已经做过？
- 代码必须保持既有的分层约束：`renderer` 不直接编排打印协议；打印协议适配器只
  消费 `shared/` 已解析的场景；物理几何规则只存在一份。
- 不确定时，默认选择「更小的改动 + 先提问」，而不是「更大的重构 + 事后解释」。

## 治理

- **修正程序**：任何原则的增删改都必须记录版本变更、动机与受影响产物；修改
  宪法本身同样受原则 II 与 III 约束。
- **版本策略**：采用语义化版本。删除或重定义原则 → MAJOR；新增原则或实质性
  扩展 → MINOR；措辞澄清、错别字、非语义调整 → PATCH。
- **合规审查**：每个变更在合并前 MUST 自查本宪法；违反原则的变更不得以「赶
  进度」为由合入。发现宪法与现实冲突时，先修订宪法或明确例外，不允许静默偏离。
- **文件位置**：本宪法位于 `.specify/memory/constitution.md`；相关计划、规格与
  任务文档应引用本文件，而不是复制其内容。
