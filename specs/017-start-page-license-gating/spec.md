# Feature Specification: Start Page Member Panel and Edition Authorization Gating

**Feature Branch**: `017-start-page-license-gating`

**Created**: 2026-10-22

**Status**: Draft

**Input**: User description: "起始页设计做大的调整，左侧显示用户的头像、手机号、公司名称、当前版本（购买付费版的入口，购买要先登录注册）、过期时间信息、商城入口，右侧默认没登录情况下显示宣传banner、历史打开的模板列表、以及云模板库，登录后显示自己上传的云模板；用户打开软件，如果没有登录或者没有插入加密狗的情况下不能新建和修改文件。不同版本的用户使用某些功能会有区别，功能的限制不同版本有所区别，插入加密狗了后可以使用全部功能。"

## Clarifications

### Session 2026-10-22

- Q: 商城里的会员套餐如何对应到标准版/专业版/企业版？ → A: 每个版本有独立的套餐（月付/年付）；账号当前生效的最高版本即“当前版本”。
- Q: 只读状态下还能打开哪些模板？ → A: 本机模板、公共云模板库与“我的云模板”都可只读打开，可查看、预览、打印，不能修改或保存。
- Q: 断网启动时授权缓存允许多久？ → A: 到订阅到期日为止；到期后即使离线也按未授权（只读）。
- Q: 本期加密狗怎样才算“有效”？ → A: 以厂商工具写入的授权数据为准，桌面端只读取该结果；开发期可先用可配置设备标识适配，发布前切换到厂商授权结果。
- Q: 三档版本的功能分档能否先用粗粒度矩阵？ → A: 采用“基础 / 效率 / 企业”分档：标准版基础设计打印；专业版增加数据库/批量数据/打印记录；企业版增加云端与共享模板/脚本/电子秤/RFID/全部条码类型。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 未授权时保持只读 (Priority: P1)

操作员打开软件时既没有登录会员账号，也没有插入授权加密狗。软件仍然可以启动、打开已有模板并查看内容，但所有“新建标签”和“修改文件”的入口都被禁用并说明原因；操作员按提示登录或插入加密狗后，无需重启即可继续编辑。

**Why this priority**: 这是本特性的商业与授权底线；如果未授权仍可编辑，版本区分和付费入口都失去意义。

**Independent Test**: 在全新、未登录、未插入加密狗的环境中启动应用：点击新建、工具栏对象工具、菜单中的编辑命令、快捷键与画布拖动，均无编辑效果并出现统一的授权提示；登录有效会员后，同一批入口立即可用。

**Acceptance Scenarios**:

1. **Given** 未登录且未插入加密狗，**When** 点击“新建标签”或任何对象工具，**Then** 不创建文档/对象，显示“需要登录有效会员或插入授权加密狗”的提示，并保留当前画面。
2. **Given** 未登录且未插入加密狗，**When** 打开本机模板、公共云模板或“我的云模板”中的模板，**Then** 都可以查看、缩放、预览和打印，但属性修改、删除、拖拽、粘贴、保存均不可用，界面进入只读状态。
3. **Given** 只读状态，**When** 通过菜单、工具栏、快捷键或右键菜单尝试编辑，**Then** 所有入口给出同一授权原因，而不是静默无效或部分入口仍可编辑。
4. **Given** 已登录但订阅无效（未订阅/已过期）且未插入加密狗，**When** 尝试新建或修改，**Then** 进入只读并提示续费或插入加密狗。
5. **Given** 只读状态下登录了订阅有效的会员（或完成续费），**When** 返回应用，**Then** 编辑入口按该会员版本恢复，无需重启。
6. **Given** 只读状态下插入了有效加密狗，**When** 应用识别到加密狗，**Then** 全部功能立即可用（包括会员版本未开放的功能），无需重启。
7. **Given** 正在编辑且授权失效（会员到期或加密狗被拔出），**When** 下一次修改操作发生，**Then** 应用进入只读并保留所有未保存内容，不得静默丢弃或自动保存。

### User Story 2 - 起始页左侧会员面板 (Priority: P1)

会员打开起始页，左侧面板显示自己的头像、脱敏手机号、公司名称、当前版本、会员有效期/过期时间，以及购买/续费和商城入口。未登录时面板显示登录入口；点击购买会先要求登录或注册，完成后再进入购买页。

**Why this priority**: 起始页是会员了解自身权益和续费的主要入口，也是商城导流的落点。

**Independent Test**: 使用有效会员登录后进入起始页，左栏依次显示头像、脱敏手机号、公司名称、当前版本、有效期至某日、“购买/续费”和“商城”；未登录时左栏显示登录按钮，点击购买先出现登录/注册流程。

**Acceptance Scenarios**:

1. **Given** 已登录会员且资料完整，**When** 打开起始页，**Then** 左栏显示头像、脱敏手机号、公司名称、当前版本与有效期；有效期已过时显示“已过期”及过期日期。
2. **Given** 会员未上传头像或资料中没有公司名称，**When** 打开起始页，**Then** 头像使用默认占位图，公司名称显示“未填写”，不得显示空白或报错。
3. **Given** 未登录，**When** 查看左栏，**Then** 显示登录/注册入口，不显示虚假的会员信息。
4. **Given** 未登录，**When** 点击“购买/续费”，**Then** 先进入登录/注册流程；登录成功后继续到购买页，不得跳过登录直接下单。
5. **Given** 已登录，**When** 点击“商城”，**Then** 打开商城入口；该入口在登录与未登录状态下都可见、可点击。
6. **Given** 当前账号未订阅任何版本，**When** 查看左栏，**Then** 版本区显示“未订阅”，并突出购买入口。

### User Story 3 - 起始页右侧内容随登录态变化 (Priority: P2)

未登录时，起始页右侧显示宣传 banner、最近打开过的模板列表和公共云模板库；登录后，云模板区域切换为“我上传的云模板”。最近模板与 banner 在两种状态下都保留。

**Why this priority**: 右侧承担“没有打开文档时做什么”的引导，同时把公共模板与个人资产区分开。

**Independent Test**: 未登录时右侧出现 banner、最近模板和云模板库；登录后同一位置出现“我的云模板”，其中只包含当前账号上传的模板，切换账号后列表随之变化。

**Acceptance Scenarios**:

1. **Given** 未登录且本机有历史记录，**When** 打开起始页，**Then** 右侧显示宣传 banner、最近打开的模板（最近若干条）和云模板库三个区域。
2. **Given** 本机没有历史记录，**When** 打开起始页，**Then** 最近模板区域显示空状态说明，而不是空白区域。
3. **Given** 未登录，**When** 点击云模板库中的模板，**Then** 按该模板的访问规则处理：可公开下载的直接打开；需要登录的提示先登录，登录后回到该模板。
4. **Given** 已登录，**When** 打开起始页，**Then** 云模板区域标题为“我的云模板”，只显示当前账号上传的模板，并支持打开/加载。
5. **Given** 已登录但账号没有上传过模板，**When** 查看“我的云模板”，**Then** 显示空状态与“上传模板”的引导。
6. **Given** 应用内登录状态发生变化，**When** 返回起始页，**Then** 右侧内容立即切换，无需重启。
7. **Given** 云模板列表加载失败（断网或服务不可用），**When** 打开起始页，**Then** 显示可重试的错误提示，且不影响最近模板和 banner 的显示。

### User Story 4 - 不同版本的功能差异 (Priority: P2)

不同版本的用户看到并可使用不同范围的功能；受限功能在界面上明确标识为当前版本不可用，并引导升级或插入加密狗。插入加密狗后，所有版本限制全部解除。

**Why this priority**: 版本差异是付费产品的核心价值；如果限制不清晰，用户会误以为软件故障。

**Independent Test**: 分别用标准版、专业版、企业版的有效授权启动应用，对照功能矩阵检查受限项：受限功能不可执行并显示升级提示；插入加密狗后同一功能在任一版本下都可用。

**Acceptance Scenarios**:

1. **Given** 当前版本的功能矩阵不包含某功能，**When** 用户查看菜单/工具栏/对话框，**Then** 该功能被标记为不可用，并说明需要升级或插入加密狗。
2. **Given** 某功能被版本限制，**When** 用户通过快捷键或菜单尝试执行，**Then** 不产生效果并显示与界面一致的升级提示。
3. **Given** 任一版本，**When** 插入有效加密狗，**Then** 该版本的全部功能限制解除，与最高版本一致。
4. **Given** 加密狗被拔出，**When** 下一次操作发生，**Then** 恢复该版本原有的功能限制。
5. **Given** 版本在登录后发生变化（购买/续费成功），**When** 返回应用，**Then** 功能可用范围立即更新，无需重启。

---

### Edge Cases

- 未登录但插入了有效加密狗：允许编辑且全部功能可用；左栏仍保持未登录信息与登录入口。
- 已登录但会员已过期、且没有加密狗：进入只读；左栏显示“已过期”与续费入口。
- 已登录但订阅尚未生效（例如刚下单未支付）：按无订阅处理，进入只读并提示完成购买或插入加密狗。
- 正在编辑时会话失效、订阅到期或加密狗被拔出：保留全部标签页与未保存内容，切换为只读并在状态栏提示；重新获得授权后可继续编辑。
- 启动时网络不可用：使用最近一次成功校验的授权缓存，可用到订阅到期日；订阅已到期或从未成功校验时按未授权处理（只读）。
- 同一账号在另一台设备登录或授权被回收：本机在下一次校验后按最新结果调整权限。
- 会员资料缺少头像、公司名称或手机号：分别使用占位图、“未填写”、脱敏占位，不阻断页面。
- 云模板服务超时：右侧其它区域正常显示，云模板区域提供重试。
- 购买过程中关闭购买窗口或登录失效：返回起始页并保持原来的登录/版本状态，不产生半完成的订单状态。
- 加密狗插入但授权已过期/损坏/未写入：视为未授权设备，提示检查加密狗或联系厂商，不解除任何限制。
- 只读状态打印含序列号的模板：输出当前序列号，但不推进序列号、不自动保存；下次打印仍从同一序列号开始。
- 厂商授权读取失败（驱动/工具缺失、设备无法访问）：视为未授权，提示安装/检查厂商工具，不得回退到“标识匹配即放行”。

## Requirements *(mandatory)*

### Functional Requirements

#### 起始页布局与会员信息

- **FR-001**: 起始页 MUST 采用左右两栏布局：左栏为会员与购买信息，右栏为内容区。
- **FR-002**: 左栏 MUST 显示会员头像；无头像时 MUST 显示默认占位图。
- **FR-003**: 左栏 MUST 显示脱敏手机号，不得显示完整手机号。
- **FR-004**: 左栏 MUST 显示公司名称；资料中无公司名称时 MUST 显示“未填写”。
- **FR-005**: 左栏 MUST 显示当前版本名称与订阅状态：未订阅、标准版、专业版或企业版，并标明有效/已过期。当前版本取账号当前有效的版本中最高的一档；仅有加密狗授权时 MUST 显示“加密狗（全部功能）”。
- **FR-006**: 购买/续费页 MUST 按版本展示对应的套餐（每个版本有独立的月付/年付套餐）；续费 MUST 延续同一版本的有效期。购买入口 MUST 能直接到达商城的购买/续费页，具体深链由商城提供。
- **FR-007**: 左栏 MUST 显示会员有效期或过期日期；永久授权 MUST 显示“永久有效”一类的明确说明。
- **FR-008**: 左栏 MUST 提供“购买/续费”入口；未登录时 MUST 先完成登录或注册，再继续购买流程。
- **FR-009**: 左栏 MUST 提供商城入口，登录与未登录状态下都可用。
- **FR-010**: 登录状态或会员资料变化后，左栏 MUST 在不重启应用的情况下更新。

#### 起始页右侧内容

- **FR-011**: 未登录时，右栏 MUST 同时显示宣传 banner、最近打开的模板列表和云模板库。
- **FR-012**: 已登录时，右栏 MUST 保持 banner 与最近模板，并将云模板区域切换为“我的云模板”（当前账号上传的模板）。
- **FR-013**: 最近模板列表 MUST 按最近打开时间排序，并支持点击直接打开；无记录时 MUST 显示空状态。
- **FR-014**: 云模板区域 MUST 支持加载失败提示与重试，且失败不得影响右栏其它区域。
- **FR-015**: 未登录时点击需要登录才能使用的云模板，MUST 先引导登录，登录成功后继续打开该模板。
- **FR-016**: 右栏内容 MUST 在登录/退出后立即切换，且不丢失最近模板记录。

#### 授权与编辑门槛

- **FR-017**: 有效会员登录（订阅有效）与有效加密狗二者满足其一即可编辑；两者都不满足时，应用 MUST 禁止新建文档和修改文档内容。仅登录但订阅无效不算“有效会员”。
- **FR-018**: 只读状态下 MUST 仍允许打开本机模板、公共云模板库与“我的云模板”中的模板，查看画布、预览和打印；打开云端模板 MUST NOT 被当作“新建文档”而拒绝。只读打印 MUST NOT 推进序列号，也 MUST NOT 触发自动保存。
- **FR-019**: 只读状态 MUST 覆盖所有编辑入口：菜单、工具栏、快捷键、右键菜单、画布拖拽/缩放/属性修改和保存操作。
- **FR-020**: 每个被禁止的入口 MUST 给出统一的、可操作的提示（登录/续费/插入加密狗），不得静默失败。
- **FR-021**: 登录有效会员或插入有效加密狗后，编辑能力 MUST 在同一会话内立即恢复，无需重启。
- **FR-022**: 插入有效加密狗 MUST 解除所有版本功能限制，使用户可以使用全部功能。
- **FR-023**: 有效性的判定 MUST 以可验证的授权结果为准；不得因为界面状态、缓存伪造或本地开关而提升权限。
- **FR-024**: 授权状态（登录、订阅、加密狗）在运行中变化时 MUST 在限定时间内反映到编辑能力上；授权失效时 MUST 保留未保存内容并切换只读，禁止自动保存或丢弃。
- **FR-025**: 启动时若无法在线校验授权，MUST 使用最近一次成功校验的本地授权，允许离线使用到订阅到期日为止；订阅已到期或从未成功校验时 MUST 按未授权处理。网络失败 MUST NOT 清除最近一次成功校验的授权记录；只有服务端明确拒绝（如 401）时才可清除。加密狗授权不受此缓存规则影响。
- **FR-026**: **发布构建** MUST 以厂商工具写入的授权数据为唯一有效性来源；应用 MUST 读取该结果，MUST NOT 允许用户通过本地开关覆盖。开发期适配器仅在非打包构建生效，且不得作为发布有效性来源。应用 MUST 在启动时检测，并在状态变化后 2 秒内反映到授权状态（检测时延见 Success Criteria）。
- **FR-027**: 加密狗存在但厂商授权无效（未写入、已过期、损坏或被拒绝）或授权数据无法读取时 MUST 视为未授权，并给出区别于“未插入”的提示。
- **FR-028**: 加密狗读取适配 MUST 集中在一处、可整体替换；在厂商读取接口到位前，可配置设备标识只作为开发期适配，发布前 MUST 切换到厂商授权结果，且不得改变受保护功能的可用性判断。

#### 版本能力差异

- **FR-029**: 应用 MUST 维护一份唯一的版本功能矩阵，覆盖所有受版本限制的功能。
- **FR-030**: 同一受限制功能在菜单、工具栏、快捷键、对话框和命令执行层 MUST 得出一致的可用性判断。
- **FR-031**: 受限功能 MUST 在界面上明确标记为当前版本不可用，并提供升级/插入加密狗入口。
- **FR-032**: 购买或续费成功导致版本变化后，功能范围 MUST 在不重启的情况下更新。
- **FR-033**: 加密狗 MUST 覆盖版本矩阵，使任一版本在插入后拥有全部功能。
- **FR-034**: 版本集合为**标准版、专业版、企业版**，未订阅账号不属于任何版本。每个受版本限制的功能 MUST 在下表的功能矩阵中明确对应三档版本的可用性；该矩阵 MUST 为唯一判定依据。

#### 版本功能矩阵（初版）

| 功能类别 | 标准版 | 专业版 | 企业版 |
|----------|--------|--------|--------|
| 基础标签设计（新建/打开/修改/保存）、打印与预览、常用条码、文字/图片/线条/表格 | 可用 | 可用 | 可用 |
| 数据库数据源（文本/Excel/ODBC/云端） | 不可用 | 可用 | 可用 |
| 批量数据与变量数据源（序列号/日期时间/键盘输入） | 不可用 | 可用 | 可用 |
| 打印记录与打印历史 | 不可用 | 可用 | 可用 |
| 云端模板与共享模板 | 不可用 | 不可用 | 可用 |
| 脚本（VBScript）、电子秤自动打印、RFID、全部条码类型 | 不可用 | 不可用 | 可用 |

*说明*：本表是按“基础 / 效率 / 企业”划分的初版矩阵，逐项清单可在实现前由产品确认并调整；调整只影响表中条目，不改变“唯一矩阵、三处一致、加密狗解除全部限制”的判定机制。

#### 数据与隐私

- **FR-035**: 起始页 MUST 仅展示脱敏后的会员信息，日志与界面不得暴露完整手机号或授权凭据。
- **FR-036**: 授权凭据与加密狗信息 MUST 安全存储，不得以明文写入日志或模板。

### Key Entities *(include if feature involves data)*

- **会员档案**: 会员身份、头像、手机号（展示时脱敏）、公司名称、当前订阅版本与订阅状态。
- **订阅/授权**: 版本名称（标准版/专业版/企业版）、有效期、是否有效、续费状态；每个版本有独立套餐，账号当前版本取有效版本中的最高档。
- **加密狗**: 是否插入、厂商写入的授权是否有效、授权覆盖范围（本期约定为全部功能）；与登录账号相互独立。
- **版本功能矩阵**: 标准版/专业版/企业版 × 功能项的可用性对应关系，是菜单、工具栏、快捷键和命令执行的唯一判断依据。
- **模板条目**: 最近打开的模板、我的云模板、公共云模板库；包含名称、更新时间与打开入口。
- **宣传 banner**: 起始页右栏的营销内容与跳转目标。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在未登录、或已登录但订阅无效且未插入加密狗的环境中，100% 的新建与修改入口被阻止并显示授权提示（按现有入口清单逐项验证）。
- **SC-002**: 插入有效加密狗后 2 秒内，全部功能限制解除，无需重启应用。
- **SC-003**: 登录成功返回起始页后 2 秒内，左栏显示完整的会员信息，右栏切换为“我的云模板”。
- **SC-004**: 从起始页开始，已登录用户最多 3 次点击即可到达购买/续费页面；未登录用户最多 5 次点击完成登录并到达购买页面。
- **SC-005**: 授权失效（到期或拔出加密狗）时，100% 的未保存标签页保持打开，用户可从提示中明确得知如何恢复编辑。
- **SC-006**: 同一受限功能在不同界面（菜单、工具栏、快捷键）的可用性判断一致率 100%。
- **SC-007**: 起始页首次显示在 2 秒内完成（本地数据先显示，云数据可随后刷新），断网时右栏其它区域仍可用。
- **SC-008**: 用户从只读提示中 1 次点击即可到达登录、续费或加密狗说明页面。
- **SC-009**: 断网启动时，订阅未到期的有效会员 100% 可继续编辑；订阅已到期时 100% 进入只读。

## Assumptions

- 会员身份与订阅信息来自现有商城会员体系。会员资料当前不包含公司名称与头像字段；需由商城补充该两项资料，未上线前按“未填写/默认头像”展示，不阻断页面。
- 未登录时浏览公共云模板库依赖商城提供无需登录即可读取的公开目录；若服务端暂不支持匿名读取，未登录状态下点击云模板先引导登录，不降低本规格其它要求。
- **术语**：本规格中未加限定的“版本”一律指会员版本（标准版/专业版/企业版）；应用自身的版本号称为“软件版本”，仍只在标题栏与“关于”中展示，避免与会员版本混淆。
- **版本集合确定为标准版、专业版、企业版**；未订阅账号不属于任何版本，不设免费版。“有效会员”指已登录且至少有一个版本订阅有效（未过期）的账号；同时持有多个有效版本时，当前版本取最高档。
- 商城为三个版本分别提供月付/年付套餐；购买与续费都在对应版本的套餐内完成。
- 起始页右侧不再默认嵌入商城页面；商城入口移至左栏。此前“登录后右侧嵌入商城”的起始页行为由本特性取代。
- 只读状态允许查看、预览和打印已有模板；保存既有文件的修改属于“修改文件”，必须在授权后才可执行。
- 加密狗为产品方提供的 USB 授权硬件，与会员账号相互独立；授权数据由厂商工具写入，桌面端读取该结果作为唯一有效性来源。开发期可先用可配置设备标识适配，发布前切换到厂商授权结果。
- **D-01（待产品确认）**：初版功能矩阵见 FR-034 后的“版本功能矩阵（初版）”。逐项清单可由产品在实现前确认或微调；在最终确认前按初版执行，不得在矩阵之外临时限制功能。
- **D-02（待厂商/产品提供）**：桌面端读取加密狗授权数据的接口方式（厂商 SDK、设备文件或系统接口）与授权数据格式；该依赖不改变本规格的行为要求。
- 授权校验允许离线缓存，缓存有明确有效期；任何情况下都不允许通过本地状态直接提升权限。
- 最近打开模板保留本机历史记录；具体保留条数沿用现有产品行为，不因登录状态变化而清空。
