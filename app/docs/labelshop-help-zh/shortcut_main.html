 快捷键

      签赋LabelShop 支持键盘快捷键操作。

文件操作

CTRL + N           新建标签模板
CTRL + O           打开标签模板
CTRL + W          关闭当前标签模板
CTRL + S            保存当前标签模板
CTRL + P            打印当前标签模板

撤消/重做

CTRL + Y            重做撤消的操作
CTRL + Z            撤消上步操作

选取对象

CTRL + A            选取模板上的全部对象
CTRL + T            依次选取模板上的对象
TAB                    依次选取模板上的对象

拷贝粘贴

CTRL + C            复制当前选取的对象到系统剪切板
CTRL + V            粘贴系统剪切板上的内容到当前模板
CTRL + X            剪切当前选取的对象到系统剪切板
SHIFT + DELETE      剪切当前选取的对象到系统剪切板
DELETE               删除当前模板上被选取的对象
ALT + RETURN      显示当前选取的对象的属性对话框

移动对象

DOWN                 向上移动当前选取的对象
LEFT                     向左移动当前选取的对象
RIGHT                  向右移动当前选取的对象
UP                       向下移动当前选取的对象

排列对象

CTRL + G            组合当前选取的对象
CTRL + U            对当前选取的对象解除组合
CTRL + L            锁定/解除锁定当前选取对象的位置
CTRL + B            将当前选取的对象移到最后

帮助

F1                         显示系统帮助信息

定位数据库记录

CTRL + F            打开数据库记录定位对话框

导出条码图片

CTRL + E            打开导出条码到图片对话框

显示

CTRL + “+”       放大显示比例
CTRL + “-”        缩小显示比例
CTRL + ALT + “0"      缩放显示比例到适应窗口
空格键 + 鼠标滚轮       缩放显示比例
空格键 + 按住鼠标左键拖动      移动模板的显示画面
