 数据库中的数据

      数据库是存放与特别的主题或目的相关信息的集合，比如用于打印标签或条码的信息。我们会经常从外部数据文件(例如数据库)读取数据，并用来打印条码标签。

      从签赋LabelShop中打印出简单标签最快捷的方式是使用数据源类型中的常量选项，直接将数据输入到标签对象中。然而，往往需要从数据源文件读取并打印其中的一些或全部数据，才能生成更复杂的标签格式，而不仅仅是从键盘输入。比如，当要输出多个标签，而且每个标签中的数据都会发生变化时，当需要使用数据库、电子表格或其它程序中的数据来打印标签时，使用分隔开的数据文件通常是首选的。

      有四种数据文件类型可在签赋LabelShop中引用：

  • 文本文件  带有分隔符的文本文件。
  • EXCEL  EXCEL电子表格数据
  • ODBC 数据源  ODBC 数据库，支持包括几乎所有主流的数据库和电子表格文件格式。
  • 云端数据库  保存在账户下的云端数据库文件。

      签赋LabelShop 打印数据库中的数据时，首先要连接导入数据库，然后再将标签模板上的对象的数据源指向数据库中相应的字段 即可。
