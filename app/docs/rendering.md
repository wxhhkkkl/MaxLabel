# 统一排版与渲染

编辑器和图形输出共用 `src/renderer/src/rendering/fabricObjects.ts` 的对象工厂。
新增文字样式、形状或图像行为时，应修改该工厂，不再另外编写 Canvas 绘制分支。

- 编辑器使用交互式 Fabric Canvas，额外添加网格、选框等辅助对象。
- 预览和 Windows 图形打印使用 `print/renderLabel.ts` 的独立 StaticCanvas，从文档生成输出；不导出编辑画布。
- `rendering/pageLayout.ts` 保留毫米坐标，只在最终页面栅格化时按 DPI 取整；内容偏移不扩大纸张。
- 每个页面调用传入该页首个标签的 `labelIndex` 和 `recordIndex`；单元格相对递增，不重置任务总数。
- 中文/弧形文字指令位图复用图形渲染后再二值化。指令协议仍负责放置、旋转与发送，原生指令与完整页面还不是同一输出后端。
- 隐藏对象、不打印对象和 RFID 注释不进入图形输出；图片资源缺失和条码生成失败会抛错。
- 文档格式不变。文本背景采用 Fabric 文本背景，椭圆使用真实椭圆，弧形文字使用共享字符布局；旧模板应检查这些视觉变化。

运行 `npm run test:render` 在隐藏 Electron 窗口中验证真实 Canvas 输出，包括 DPI、数据索引、样式、可见性和单色位图像素。不连接打印机。

数据库刷新和打印任务现在具备请求取消、批次状态账本与已确认序列号提交；仍需在真实设备上验证“未知”传输状态后的人工对账策略。原生协议语法/拷贝数量已覆盖离线回归夹具，但最终仍需要各品牌设备实测。表格模型目前仅包含网格及合并信息，没有单元格内容模型。
