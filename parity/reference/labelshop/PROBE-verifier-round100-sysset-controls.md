# 真机「系统设置 → 常规」页逐控件原文（验收方 round-100 实测）

日期：2026-09-21。路径：编辑态 → `选项(O)` → `系统选项(C)...`（**注意：菜单项用 `keys:` 触发，`keydlg:` 打不到弹出菜单**）。

## 一、控件清单（tree dump 原文，含可见性）

| 控件 | 原文 | 备注 |
| --- | --- | --- |
| 分组框 | `语言` / `单位` / `非打印对象` / `其它` | 四个（`class=Button` 的 group box） |
| 语言组 | `界面语言(&L):` + 下拉 | 下拉 **3 项**：`简体中文` / `繁体中文` / `English` |
| 单位组 | `标尺单位(&U):` + 下拉 | 下拉 **2 项**：`毫米` / `英寸`（**没有"（公制）/（英制）"后缀**） |
| 非打印对象组 | `输出非打印对象(&P)`、`不选中非打印对象(&N)` | 两个复选（round-112 截图：前者 **未勾选** ☐、后者 ☐） |
| 其它组 | `允许运行脚本(&S)`、`启动时运行模板向导`、`自动旋转输出页面`、`新建对象后自动打开属性页` | **四个**复选（round-112 截图：四个都 ☑） |
| 其它组（续） | `标签工作区背景颜色：` + 颜色块按钮 + `恢复默认` 按钮 | 颜色块按钮在 tree 里叫 `Button1`（自绘） |
| 底排 | `确定` / `取消` / `帮助` | 另有 **`应用(&A)`：`[ ] DISABLED`**（**隐藏**控件，与「标签格式设置」同款） |

## 二、据此对复刻版的四条要求

1. **`标尺单位` 下拉选项文本改成 `毫米` / `英寸`**（复刻版现在写「毫米（公制）」「英寸（英制）」→ 与真机不符）；
   相应地 `ui-v103` 里引用「英寸（英制）」的断言要同步改。
2. **`界面语言` 下拉真机有 3 项**（简体中文/繁体中文/English）。复刻版目前只有「简体中文」：
   若确实只支持一种语言，**不要**为了凑数把另两项列成可选项（那是假实现）——应在 `diffs.md` 记为
   "**原版有但受限**（复刻版仅实现简体中文）"，并把下拉保持为 1 项 + 写明原因。
3. **底排补 `帮助` 按钮**（真机 `确定/取消/帮助`，`应用(&A)` 隐藏）——与 `Verify-SystemOptions` 5/6 的那条一致。
4. **「其它」组必须是 4 个复选 + 背景颜色 + `恢复默认`**：`cmp-sysset-r115.png` 里复刻版看不全，
   若只是对话框高度/滚动问题就调高度；若确实缺项则按上表补齐（不许留占位）。
