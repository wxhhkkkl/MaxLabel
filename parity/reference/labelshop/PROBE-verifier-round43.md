### 2. 「标签格式设置」现场：`孔洞=圆洞` 时尺寸框**点亮**、预览**不画孔**（`verifier-r43-hole-circle-20.png`）

- 该图里 `孔洞 = 圆洞`（由 `Probe-LabelShopCombos -SetCombo 0 -SetIndex 1` 真实改选成功：`sel=1 cur='圆洞'`），
  尺寸框 **0.00 且为可编辑态**（黑字，与 `无` 时的灰字相对）→ 与 round-107b 的结论一致。
- **新信息**：我把 `20` 打进了**高度(H)** 框（Tab 打偏），预览随即变成 `100.00 x 20.00 毫米 [4行 2列]`、卡片随之变矮
  → **说明这个预览是随字段实时重绘的**，不是静态位图；因此"改孔洞尺寸后预览仍无孔"不能归因于"预览不刷新"，
  更像是**预览根本不渲染孔洞**。
- 点「确定」后进入编辑器（`verifier-r43-editor-hole.png`，261% 缩放，100×20mm 标签）：**画布上同样看不到孔**。

## 二、没做成的部分（写清以免重复踩）

- 目标是"把孔洞尺寸改成 20 再看编辑器/输出有没有孔"，但：
  - `keydlg:{TAB}`（1 次）落到了 **高度(H)** 上，`clickdlg:573,216` 那次因为**对话框没开**而报"没有可见对话框"；
  - 从编辑态走 `文件 → 标签格式设置(L)...` 用 `{DOWN 8}{ENTER}` **没打开**（项序号猜错/菜单未开），
    所以第二次进对话框失败，本次没能把孔洞尺寸设成非 0。
- 因此**「真机是否在编辑器/打印输出里画孔」仍未取证到位**；下一步建议：先 `shotpopup:` 抓文件菜单确认项序号，
  或直接用 `Probe-LabelShopCombos` 之外的方式定位控件后再注入尺寸（注意本轮已证明：Tab 顺序里
  `高度` 与 `孔洞尺寸` 相隔多个控件，注入前必须先读焦点）。
