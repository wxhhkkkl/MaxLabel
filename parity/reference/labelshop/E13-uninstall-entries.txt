真机取证：LabelShop V6.39 的卸载入口（对应矩阵 E-13 / 帮助 install_uninstall.html）
取证时间：2026-09-17（round-90）
取证方式：只读枚举文件系统与注册表，未启动/未改动真机程序

帮助 install_uninstall.html 原文列出两个入口：
  「可以通过开始菜单 签赋LabelShop 中的"卸载 签赋LabelShop"，
    或者在"控制面版"——"程序和功能"中双击"签赋LabelShop"，启动卸载」

------------------------------------------------------------
入口一：控制面板——程序和功能
------------------------------------------------------------
命令：
  powershell -NoProfile -Command "Get-ChildItem 'HKLM:\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall','HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall' | ForEach-Object { $p=Get-ItemProperty $_.PSPath; if ($p.DisplayName -like '*LabelShop*') { $_.PSPath; $p.DisplayName; $p.UninstallString; $p.InstallLocation } }"

输出（键：HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\LabelShop）：
  DisplayName     : LabelShop
  UninstallString : C:\Program Files (x86)\LabelShop\LabelShop\labelshop_ul.exe
  InstallLocation : C:\Program Files (x86)\LabelShop\LabelShop
  DisplayIcon     : C:\Program Files (x86)\LabelShop\LabelShop\LabelShop.exe
  Publisher       : 京成云马（北京）科技有限公司

即：**卸载程序是安装目录内的一个可执行文件**，注册表 UninstallString 直接指向它。
文件确实存在：
  $ ls -la "/c/Program Files (x86)/LabelShop/LabelShop/labelshop_ul.exe"
  -rwxr-xr-x 1 liyan 197609 4188392 Jul 20  2021 .../labelshop_ul.exe

------------------------------------------------------------
入口二：开始菜单「签赋LabelShop → 卸载 签赋LabelShop」
------------------------------------------------------------
命令：
  $ ls -R "/c/ProgramData/Microsoft/Windows/Start Menu/Programs/LabelShop"
  /c/ProgramData/Microsoft/Windows/Start Menu/Programs/LabelShop:
  签赋LabelShop.lnk

  $ find "/c/ProgramData/Microsoft/Windows/Start Menu" -iname "*LabelShop*"
  /c/ProgramData/Microsoft/Windows/Start Menu/Programs/LabelShop
  /c/ProgramData/Microsoft/Windows/Start Menu/Programs/LabelShop/签赋LabelShop.lnk

  $ find "/c/Users/liyan/AppData/Roaming/Microsoft/Windows/Start Menu" -iname "*LabelShop*" -o -iname "*签赋*"
  （无输出）

  $ find "/c/ProgramData/Microsoft/Windows/Start Menu/Programs" -maxdepth 1 -name "卸载*"
  （无输出）

结论：真机安装的「开始菜单」分组 `LabelShop` 内**只有一个快捷方式** `签赋LabelShop.lnk`（应用本体），
整个「所有用户 / 当前用户」两处开始菜单树内**都不存在**指向卸载器的 .lnk。
帮助描述的入口二在这套真机安装上并不存在——真机的卸载入口是「入口一（控制面板）」加上
「安装目录内的 labelshop_ul.exe」，与 electron-builder NSIS 的出包形态同构：
  UNINSTALL_FILENAME = "Uninstall ${PRODUCT_FILENAME}.exe" 落在 $INSTDIR，
  UninstallString / QuietUninstallString = "$INSTDIR\Uninstall MaxLabel.exe" [--allusers|--currentuser] [/S]，
  注册表键同时写 32/64 位两处 Uninstall 键（NsisTarget 的 UNINSTALL_REGISTRY_KEY / _2）。

因此复刻版**不额外创建开始菜单卸载快捷方式**才是与真机一致的行为；E-13 按「与真机实测一致」收口。
