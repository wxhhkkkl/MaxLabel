## 二、结论（三态）

| 问题 | 结论 |
| --- | --- |
| 真机「条码」页（Code 128）有几个控件？ | **8 个**：码制 / X 尺寸 / 码高 / 字符集 / （无标签）位置 / 垂直偏移 / 对齐方式 / （无标签 Edit）。 |
| 真机「条码」页**有没有颜色控件**？ | **原版无**。该页 8 个控件里没有任何颜色项。round-65 的两份证据冲突到此定案：`PROBE-verifier-object-tabs.md` 里"条码页页尾有颜色"那条**不成立**。 |
| 真机的颜色在哪儿？ | **「常规」页**，控件原文 `颜色(&C):`，值域只有一项 `固定颜色`（本机 dump）。 |
| 真机字段名与复刻版的差距 | 复刻版缺加速键 `(&B)` `(&X)` `(&H)` `(&O)` `(&A)`；「码 高」少一个空格且把单位写进了标签；「供人识读字符 · XXX」是复刻版自造的前缀名（真机该项自身无标签文字，由组名承担）。 |
| 「条宽比」/「缩减量」 | 真机 Code 128 页**没有**这两项（复刻版按码制条件化显示，方向正确）。 |

## 三、本轮据此改了什么（复刻版）

`app/src/renderer/src/dialogs/ObjectPropsDialog.tsx`：

1. `条码符号类型(码制)` → **`条码符号类型(码制)(&B):`**
2. `X 尺寸` → **`X 尺寸(&X):`**
3. `码 高（毫米）` → **`码  高(&H):`**（两个空格用 NBSP + 空格实现，否则 HTML 会把连续空格折叠成一个），单位 `毫米` 改为**框后**的独立文字（与真机一致）
4. `供人识读字符 · 位置` → **`位置`**（真机该控件自身无标签文字，组名承担；此点记入 DIFF-72）。
5. `供人识读字符 · 垂直偏移（毫米）` → **`垂直偏移(&O):`**
6. `供人识读字符 · 对齐方式` → **`对齐方式(&A):`**
7. **「条码颜色」从「条码」页移到「常规」页**，按真机改名 **`颜色(&C):`**（testid `barcode-color` 不变）。

**没有改**：`条宽比` / `缩减量` 的条件化显示（与真机方向一致）；第 8 个无标签 Edit（真机有、语义未取证，**不按猜测实现**）。
