# 验收方独立量测：真机标签预览里「圆角矩形」的角弧半径（round-104）

- 日期：2026-09-21
- 量测人：验收方（不是 codex 自述）
- 目的：给 `round-focus.md` 的 **P0（用户实测反馈：各种纸张圆角弧度）** 一个可复核的标尺，
  并作为事后验收 codex 改动的依据。
- 工装：`tools/parity/measure-corner-radius.cjs`（本轮新写，只读 PNG，不改任何文件）

## 一、方法（为什么这么做）

真机预览同时画**纸张外框**与**标签格子**两套描边（相距 2–7px），外加抗锯齿，自动拟合圆角会把外框当格子
（本轮踩过：`probe-27` 的外框与格子左边缘只差 2px）。因此改为：

1. 先用暗像素行/列计数峰值定位所有横线与竖线；
2. 取**间距最大的那对竖线**当格子左右边，得到格子宽 → `mm/px` 标尺（真机预览按标签实际宽度等比画）；
3. 打印角区 **1:1 ASCII 图**（`#` 暗 / `.` 亮），人眼直接数圆弧跨几像素。

命令（可复现）：

```powershell
cd D:\workspace\maxlabel
# 平张 A4：选择标签格式对话框（100mm x 70mm 圆角8枚/页）
node tools\parity\measure-corner-radius.cjs parity\reference\labelshop\60-dlg-choose-label.png 200 50 620 540 100 276 80 40 16
# 卷筒：标签格式设置 → 标签页（100.00 x 150.00 毫米，形状=圆角矩形）
node tools\parity\measure-corner-radius.cjs parity\reference\labelshop\probe-27-roll-label-format-tab-label.png 360 40 720 520 100 422 145 40 16
```

## 二、数据点 1：100 mm × 70 mm 圆角（A4 平张，`60-dlg-choose-label.png`）

- 边线：横线 `y = 76 86 215 220 349 354 483 488`；竖线 `x = 274 281 465 470`
- 格子：`x 281..465 = 184 px` ⇒ **0.5435 mm/px**（按标签宽 100mm）
- 角区 ASCII（`x276..315 y80..95`）：

```
  86 .......#################################   ← 上边自 x=283 起
  87 ......#                                    ← x=282
  88 .....#                                     ← x=281
  89 .....#                                     ← x=281（左边线达成）
```

→ 圆弧横向跨 2px（283→281）、纵向 2 行（86→88）：**半径 ≈ 2 px ≈ 1.09 mm**

## 三、数据点 2：100 mm × 150 mm 圆角（卷筒，`probe-27-roll-label-format-tab-label.png`）

- 边线：横线 `y = 95 144 151 469 476`；竖线 `x = 424 426 638 640`
- 格子：`x 426..638 = 212 px` ⇒ **0.4717 mm/px**（按标签宽 100mm）
- 角区 ASCII（`x422..461 y145..160`）：

```
 151 ..#...##################################   ← 外框在 x=424；格子上边自 x=428 起
 152 ..#..#                                    ← x=427
 153 ..#.#                                     ← x=426（左边线与纸张内框重合）
```

→ 圆弧同样 2px：**半径 ≈ 2 px ≈ 0.94 mm**

## 四、结论

1. **真机预览里圆角矩形的角弧只有约 2 像素**，换算成物理尺寸约 **0.9–1.1 mm**；
2. **两种完全不同的标签尺寸（100×70 与 100×150）量出来都是 2px** —— 也就是说
   **原版预览的圆角弧度与标签尺寸无关**，不是按比例的；
3. 复刻版现状（`paper.ts` / `PaperFields.tsx` / `LabelEditor.tsx`）用 `min(宽,高) × 0.12`：
   100×70 → **8.4 mm**（在这张预览的尺度下应是 ~15px）、100×150 → **12 mm**（应 ~25px），
   比真机**大约 7 倍** —— 这就是用户说的「圆角不一样」；
4. 另有一条同向的侧面证据：真机「标签格式设置 → 标签」页**根本没有「圆角半径」输入框**
   （`61-dlg-custom-label.png` / `probe-27-...png` 都只有 形状 下拉），说明这个弧度不是用户可设参数。

## 五、仍未定的部分（不要在没证据前下结论）
- 上面量的是**对话框里的原理图预览**。原版**编辑画布**和**打印输出**上的圆角半径是不是同一个值，
  必须另做一次取证：在真机里打开一个 `Corner=1` 的圆角格式，把视图放大到 ≥200% 后截图，
  再用同一套 1:1 像素法量（缩放倍数从状态栏读，或用画布上的毫米标尺当标尺）。
- 两种可能必须靠那次高倍测量区分：
  - **固定物理值**（如 1 mm）→ 复刻版应把它做成常量，画布/打印按 mm 换算；
  - **固定屏幕像素**（原理图里固定 2–3px）→ 复刻版预览也按屏幕像素画，而画布/打印需另取真机值。
- 在拿到画布证据前，**不要**把 12% 直接改成某个猜的常量；至少不能用「看起来差不多」当依据。
