# round-112 真机取证：`选项(O) → 系统选项(C)...` 打开的「系统设置」对话框（四个页签全部拍全）

日期：2026-09-21（循环 round 112）。真机：签赋 LabelShop V6.39 标准版-未激活。
目的：回答 **DIFF-67** 挂起的问题——真机「系统设置」里到底有没有「形状」下拉（复刻版 `OptionsDialog.tsx:266` 写的是 `直角矩形`）。

## 一、结论（三态）

| 问题 | 结论 |
| --- | --- |
| 真机「系统设置」里有没有「外观形状 / 直角矩形·圆角矩形·圆形」下拉？ | **原版无**。四个页签（常规 / 打印和数据库 / 编辑 / 系统）逐页拍全，**没有任何形状下拉**，也没有「默认标签尺寸 / 排列 / 行列间隔」。 |
| 真机「系统设置」的页签是哪几个？ | `常规` / `打印和数据库` / `编辑` / `系统`（左→右，4 个）。 |
| 真机「系统设置」的窗口标题？ | `系统设置`（菜单项叫「系统选项(C)...」——菜单名与窗口标题不一致）。 |
| 真机「系统设置」底部按钮？ | `确定` / `取消` / `帮助`；另有 **`应用(&A)` 是隐藏控件**（dump 行首 `[ ]`，与「标签格式设置」同款）。 |

→ 因此 DIFF-67 的正确处置**不是**把 `直角矩形` 改名为 `方角矩形`：那个下拉所在的整个「标签」页在真机里**没有对应物**，
属于复刻版自造，已另登记 **DIFF-71**（页签结构差异）。

## 五、本轮据此改了什么（复刻版）

`app/src/renderer/src/dialogs/OptionsDialog.tsx`：

1. 窗口标题 `系统选项` → **`系统设置`**（真机原文）。
2. 页签 `通用` → **`常规`**；`打印参数` → **`打印和数据库`**（两个都是真机页签名）。
3. 常规页按真机加**四个分组框** `语言/单位/非打印对象/其它`（`data-testid="options-group-<名>"`），
   字段文案改真机原文（含加速键）：`界面语言(L):` / `标尺单位(U):` / `输出非打印对象(P)` /
   `不选中非打印对象(N)` / `允许运行脚本(S)` / `标签工作区背景颜色：`。
4. 补上真机常规页有、复刻版原先漏掉的 **`启动时运行模板向导`** 复选框（落到「其它」分组，从「打印和数据库」页移过来）。
5. 底部按钮 `保存` → **`确定`**（真机原文；`应用(&A)` 真机是隐藏控件，故不显示）。
6. `云服务器地址` 是复刻版自有扩展项（真机无），保留但不放进任何真机分组框内。

**没有改的**：`OptionsDialog.tsx` 里那个 `直角矩形` 下拉本身——它所在的「标签」页在真机无对应物，
按「不许按猜测造功能 / 也不许凭空删功能」的口径，登记为 DIFF-71 待与真机页签结构一并收口。
