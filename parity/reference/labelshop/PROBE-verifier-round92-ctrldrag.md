# P2-① / DIFF-71 合并取证（验收方 round-92）：「鼠标拖动复制」的现状与卡点

## 一、已确证（来自真机 dump，非推断）

真机「系统设置 → **编辑**」页有一个选项：**`☐禁用鼠标拖动复制功能`**（round-112 取证，见 `PROBE-round112-sysset.md`）。
→ 该选项名的存在本身说明：**真机默认「鼠标拖动对象＝复制」**，这个开关是用来**关掉**复制行为的。
（对应复刻版现状：round-114 明确"复刻版没有对应行为"、按"不许留假实现"不渲染 —— 因此这条既是 **P2 第 1 问**的答案方向，
也是 DIFF-71 里未收口的一项。）

## 二、本轮**未完成**的部分（如实登记）

我尝试在真机上直接做「拖动 + CTRL+拖动」的对照实测，**没做成**，卡点写清如下：

| 尝试 | 结果 |
| --- | --- |
| `工具(T)→文字(T)` + `postclick:docview\|300,220` | 「文字属性」对话框**确实打开**（说明对象被建），但点「确定」后**画布上看不到对象** |
| 随后 `选取` + `postdrag:docview\|300,220\|430,330` | 画布**仍为空** → 说明对象落在了**标签白区之外**（或不可见），拖拽自然没有可观察效果 |
| 用状态栏「鼠标: X, Y 毫米」读数反推坐标映射 | `listctl:鼠标` **命中 0 个控件** —— 状态栏那几段是自绘/无文本，读不到 ✗ |
| `postdrag` 直接创建对象（ctl 注释称"原版对象是按住拖出一个矩形创建的"） | 拖完画布仍为空；状态栏出现 `宽/高` 数值（说明拖拽被受理），但对象未出现 ✗ |

**根因判断**：`postclick/postdrag` 传给 docview 的**客户端坐标与画布坐标的映射没校准**，
我用的 `(300,220)` 可能落在标签白区（截图里白区大约对应 docview 客户端 x≈110–1450、y≈60–1150）之外，
或落在"页边距"区域导致对象不可见。

## 三、坐标映射已校准（round-93 实测，供以后所有真机画布操作复用）

用「在已知 docview 客户端点 postclick → 截全窗 → 读状态栏 `鼠标: X, Y 毫米`」两点法反推（**状态栏文本 listctl 读不到，只能看图**）：

| docview 客户端点 | 状态栏读数（标签毫米） |
| --- | --- |
| `(200, 200)` | `11.80, 6.09` |
| `(800, 900)` | `52.32, 53.39` |

→ **线性映射**（各向同性，误差 <0.1%）：

```
标签毫米 → docview 客户端：  X = 25.3 + mm_x * 14.81
                            Y = 109.9 + mm_y * 14.80
即：标签原点 (0,0) ≈ docview 客户端 (25, 110)；100% 缩放下 1mm ≈ 14.8 px（不是复刻版的 10px/mm）
```
例：标签正中 (50, 35) mm → docview 客户端 **(766, 628)**。

## 四、另一条更重要的发现：**PostMessage 驱动编辑后，画布截图可能是"没重绘"的旧画面**

用上面校准过的、**确定落在标签内**的点（例如 `(300,220)` → 标签 (18.6, 7.4) mm，`(766,628)` → (50,35) mm）
建对象后点「确定」，**截图里画布仍是空白** —— 但同一时刻「文字属性」对话框**确实打开过**（等于对象已建）。
最可能的解释：`postclick/postdrag` 是 **PostMessage 注入**，应用没有走真实输入路径触发重绘，
于是**截图拿到的是未更新的画布**（对象在，但位图是旧的）。

**影响**：**不能用"截图里有没有对象"来判定真机画布状态** —— 这会同时解释 round-92 的两次"拖了没反应"。
**下一步建议**（未验证）：编辑后先想办法强制重绘（切到别的窗口再切回 / 缩放一次 / 拖一下分隔条），再截图；
或者改用**对象计数**（左侧「图层」面板的行数）而不是看画布。

## 五、下一次的做法（给后来者省时间）

1. **先校准**：把鼠标移到几个已知点，用 `shotmain:` 截图 + 状态栏肉眼读「鼠标: X, Y 毫米」（截图里能看清），
   反推出 docview 客户端 → 标签毫米 的线性映射；**不要**再用 `listctl` 去读状态栏（读不到）。
2. 校准后，在标签**正中**（约 50mm, 35mm 处）建对象；建完先截图确认对象**可见**，再做拖拽对照：
   ① 普通拖动 → 原位置是否还留一个（复制）？② `keys:{CTRLDOWN}` + `postdrag` + `keys:{CTRLUP}` → 是否行为不同？
3. 判定"复制 vs 移动"只看**对象个数**：真机左侧「图层」列表会随对象数变化，用它计数比看画布更稳（截图可见该面板）。

## 四、对复刻版的当下结论（不因本次未完成而改变）

- `禁用鼠标拖动复制功能` 这条**仍按"复刻版无对应行为"**登记在 DIFF-71 未收口；
- **不要**凭"选项名"就实现一套"拖动即复制"的行为 —— 选项名只证明真机**有**这个可禁用项，
  没有实测证据证明"复刻版现在的拖动是移动"就是错的。**先实测，再实现**。
