# DIFF-63 真机取证（验收方 round-88）：序列号「重置」按钮的真实形态

日期：2026-09-21。路径：真机 → 新建标签模板 → 工具(T)→文字(T) → 画布落点建对象 → 双击对象打开「文字属性」
→ 数据源(S) 选 **序列号** → 点 **高级选项(A)...** → 得到标题为 **「高级选项」** 的序列号设置对话框。

## 一、结论（三态）

| 问题 | 结论 | 证据 |
| --- | --- | --- |
| 真机序列号设置里有「重置」类按钮吗？ | **原版有，但只有一个，且（本机可达状态下）恒为禁用** | 控件树：`[V] class=Button DISABLED text='重置' xy=(987,878) wh=(586x171)` |
| 有没有「立即重置」这个按钮？ | **原版无** | 该对话框控件树里没有"立即重置"字样（只有 `重置` 一个） |
| 启用条件是什么？ | **本机未能触发**：`初始值来源(&R)` = `默认` 与 = `键盘输入` 两种状态下，`重置` **都是 DISABLED** | 两次 dump + 两张截图（`r88-serial-advanced.png` / `r88-serial-keyboard.png`） |
| 还有别的相关控件吗？ | 有若干**隐藏**控件：`提示(&P):` + 其 Edit、`归位` 按钮、两个 Edit（`[ ]` 行首表示不可见） | 同上 dump |

## 二、该对话框的完整控件（可见项，逐字）

| 控件 | 原文/取值 |
| --- | --- |
| 类型(&T): | 下拉 4 项：`10进制(数字)` / `26进制(字母)` / `36进制(数字和字母)` / `16进制(0-9，A-F)`（本机默认第 1 项） |
| 序列(&Q): | Edit，本机 **DISABLED**，值 `0123456789` |
| 步长(&S): | Edit `1` ＋按钮 `增量(&A)` / `减量(&D)` |
| 重复(&E): | Edit `1` ＋下拉 2 项：`记录数` / `标签数` |
| 初始值来源(&R): | 下拉 2 项：`默认` / `键盘输入` |
| **重置** | Button，**DISABLED** |
| （隐藏） | `提示(&P):`、`归位`、两个 Edit |

## 三、对复刻版的要求（把 DIFF-63 收口）

1. 复刻版里若有**两个**按钮（"重置初始值 / 立即重置"）→ 与真机不符：真机只有**一个 `重置`**；
   请改成单一 `重置`，并**默认禁用**（与真机一致）。
2. `重置` 的**启用条件真机未取到**（两种初始值来源下都禁用）→ 按"待取证"处理：
   复刻版保持禁用即可，**不要**为了实现"可用"而猜一个条件；在 `diffs.md` 写明"启用条件未知，本机观测恒禁用"。
3. 序列号对话框的字段名字与选项请照上表逐字对齐（`类型(&T):`/`序列(&Q):`/`步长(&S):`/`重复(&E):`/`初始值来源(&R):`）。
