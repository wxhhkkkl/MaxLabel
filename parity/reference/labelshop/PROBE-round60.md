# round-60 真机取证：序列号数据源面板的字段集（判定需求清单第 201 条「边界值」）

日期：2026-09-21　对象：真机签赋 LabelShop 标准版-未激活 V6.39（`C:\Program Files (x86)\LabelShop\LabelShop\LabelShop.exe`）

## 一、为什么这么取证

需求清单第 201 条是「序列号 → 边界值（暂不支持）」，帮助 `datasource_type_serial.html` / `label_object_page_data_serial.html`
都没有这一项，真机数据源页又因为「切源后页面不重排」读不到序列号子面板（round-58/59 记录的工装限制）。
本轮换了两条不依赖页面重排的路子：

1. **EXE 字符串资源取证**（不依赖 UI）：对话框控件标题在 Win32 资源里必然是字符串。
   直接把 `LabelShop.exe` 按 UTF-16LE 与 GBK 两种编码全文解码后正则检索。
2. **页面重排再验证**：新写 `tools/parity/Probe-LabelShopSerialPage.ps1`，
   先把数据源下拉切回「常量」再切到「序列号」（制造一次真实变更），并补发
   `CBN_SELCHANGE(1)` / `CBN_SELENDOK(9)` 与下拉自身的回车键，然后 dump 数据源页的全部子控件（含隐藏）。

## 二、结果

### 2.1 序列号面板的控件标题（EXE 字符串资源，UTF-16LE，`LabelShop.exe`）

在「归位」字符串 ±1500 字符的同一资源块里，连续出现的数据源/序列号面板标题为：

```
数据源(&S): | 显示数据(&D): | 字段名(&F): | 偏移(&O): | 变量共享名称(&N): | 高级选项(&A)...
子串列表 | 子串选项 | 示例 | 使用打印机时钟 | 库连接(&D): | 显示特殊字符 | 源自其它变量
序列号 | 类型(&T): | 序列(&Q): | 步长(&S): | 增量(&A) | 减量(&D) | 重复(&E):
序列号设置 | 重置 | 提示(&P): | 归位 | 初始值来源(&R): | 数据库连接(&D): | 重置初始值: | 立即重置
截短与验证 | 删除左侧空格(&L) | 删除右侧空格(&R) | 丢弃左侧(&D): | 丢弃右侧(&C): | 保留(&K):
许可字符(&I): | 字符(&S): | 非法字符(&N): | 字符(&T): | 截短字符串 | 个字符 | 字符验证
字符数限制 | 限制最小字符数(&S) | 最小字符数(&N): | 长度不足时(&T): | 填充字符(&C):
限制最大字符数(&L) | 最大字符数(&M): | 长度超过时截去(&W): | 多余字符 | 长度下限 | 长度上限
```

关键词计数（同一 EXE，UTF-16LE）：

| 关键词 | 出现次数 |
| --- | --- |
| 序列号 | 12 |
| 步长 | 1 |
| 归位 | 1 |
| 边界 | 10（3 处上下文：「边界距离」×2〔定位裁切标记〕、警告语「标签超出了纸张的右侧/底部边界」） |
| **边界值** | **0** |
| 起始值 / 最大值 / 最小值 / 递增 | 0 |

`LabelShopEng.dll` 里「边界」「边界值」「归位」同样是 0（「序列号」1 次）；帮助 `LabelShop.chm` 是压缩格式，
解出来的帮助页（`parity/reference` 下的副本）也没有「边界值 / 立即重置 / 重置初始值 / 归位」这些词。

**结论：原版没有名为「边界值」的控件。** 检索方法是灵敏的——同一次检索能命中间一面板的
「序列号」「步长」「归位」「显示数据」等标题，唯独没有「边界值」。

### 2.2 变量共享名称确实是可编辑组合框（本轮修正 DIFF-62 ③ 的真机证据）

`probe-60-barcode-props-tree.txt`（可见顶层窗口 `条码属性` 的递归控件树）：

```
[V] class=Static   id=1597 text='变量共享名称(&N):' xy=(1212,812) wh=(179x24)
[V] class=ComboBox id=1507 text=''                 xy=(1212,842) wh=(407x32)
    [V] class=Edit  id=1001 text=''                 xy=(1215,845) wh=(375x26)
```

→ 组合框 + 内嵌编辑框 = 可下拉选、也可手输。复刻版本轮挂 `datalist` 与此形态一致。

### 2.3 数据源下拉仍是 7 项（再次实证）

`Probe-LabelShopCombos.ps1 -TitleLike '*条码属性*'`：`combo[0] id=1516 count=7 sel=1`，
项为 常量 / 序列号 / 数据库 / 日期 / 时间 / 键盘输入 / 脚本。

### 2.4 页面重排仍未成功（工装限制确认）

`Probe-LabelShopSerialPage.ps1`（先常量再序列号 + SELCHANGE/SELENDOK + 回车）后，
数据源页可见控件依旧是常量态：

```
[V] Static  id=1506 '显示数据(&D):'
[V] Edit    id=1500
[V] ComboBox id=1516（数据源，sel=1=序列号）
[V] Static  id=1597 '变量共享名称(&N):' / ComboBox id=1507 / Edit id=1001
[V] Button  id=1517 '高级选项(&A)...'
```

序列号子面板的控件在子窗口列表里**连隐藏态都不存在**（`[ ] 字段名 / 偏移 / 使用打印机时钟 / 显示特殊字符 / 源自其它变量`
是日期/时间/数据库/脚本子面板的隐藏控件），说明序列号子面板是选择时才动态创建的。
要让真机走到这一步，需要真实的鼠标点选（本机鼠标注入无效，见 round-114 记录），
所以「序列号子面板的最终字段布局」仍留作真机点按待办。

## 三、对复刻版的处置

| 清单/差异 | 处置 |
| --- | --- |
| 清单第 201 条「序列号·边界值」 | 结案为**原版无此控件**（证据：EXE 字符串资源 0 命中 + 同面板其它标题均命中 + 帮助未记载） |
| 复刻版序列号页 | 保持现状（类型/序列/显示数据/序列起始值/步长/位数/重复/变化基准/初始值来源/初始值字段/归位/示例） |
