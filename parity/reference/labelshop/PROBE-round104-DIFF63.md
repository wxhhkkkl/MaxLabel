# round-104 DIFF-63 真机取证：序列号“重置初始值 / 立即重置”

- 日期：2026-09-21
- 真机：签赋 LabelShop V6.39，先以“标准版 - 未激活”启动，取证中按原版提示进入“专业版 - 演示模式”
- 工装：`LabelShopCtl.ps1`、`Probe-LabelShopCombos.ps1`、`Read-LabelShopDialogValues.ps1`
- 对象：新建 100 mm × 70 mm 标签上的文字对象，显示数据初始为 `12345678`

## 可复现路径

1. 模板向导中新建标签并选择默认标签格式。
2. `Alt+T`、两次向下、回车选择文字工具；在画布用 `postdrag:docview|500,350|820,470` 创建文字对象。
3. `Alt+Enter` 打开“文字属性”。数据源组合框的真实 Tab 路径为从子串列表起连续 7 次 Tab，再按向下键；选择结果为“序列号”。
4. “高级选项”打开“序列号”页。完整可见默认值见 `probe-63-13-serial-advanced.png` 和 `probe-63-serial-advanced-values.txt`。
5. 初始值来源下拉用真实鼠标路径 `clickdlg:590,360` 打开，再以方向键选择；“默认 / 键盘输入”两项均已实测。
6. 将变化基准从“记录数”改为“标签数”时，标准版立即弹“功能提示”：该功能仅专业版和企业版可用；进入演示模式后出现“归位”复选框。证据为 `probe-63-temp-basis-down.png`、`probe-63-18-label-mode-demo.png`、`probe-63-20-label-mode-reset.png`。
7. 勾选打印对话框“打印后更新变量数据”，打印 1 份到 Microsoft Print to PDF。打印后“显示数据”从 `12345678` 推进为 `12345679`。证据为 `probe-63-31-print-update.png`、`probe-63-34-after-print-display.png`、`probe-63-after-print-values.txt`。

## 完整控件与默认值

“高级选项 → 序列号”页在当前可达状态下：

| 控件 | 默认值 / 枚举 | 限制 |
| --- | --- | --- |
| 类型 | `10进制(数字)`；标准版 4 项，专业版演示模式 5 项 | 自定义类型受版本限制 |
| 序列 | `0123456789` | 随类型只读显示 |
| 步长 | `1` | 增量默认选中，可切减量 |
| 重复 | `1` | 变化基准默认“记录数” |
| 变化基准 | `记录数 / 标签数` | “标签数”在标准版受限；进入专业版演示模式后可用 |
| 归位 | 默认未勾选 | 仅在“标签数”模式显示 |
| 初始值来源 | `默认 / 键盘输入` | 未连接数据库时共 2 项；键盘输入时显示“提示”输入框 |
| 重置分组 | 标题可见，内容为空 | 见下节；隐藏控件资源存在，但未找到真机可达条件 |

控件树还含隐藏的两个“重置初始值:”标签、数个组合框和“立即重置”按钮。这与 EXE 字符串资源一致，但它们在以下状态中都不可见：

- 标准版默认状态；
- 专业版演示模式；
- “记录数”与“标签数 + 归位”；
- 初始值来源“默认”与“键盘输入”；
- 打印推进前后；
- 模板保存前后；
- 设置共享变量名后。

对应截图：`probe-63-13-serial-advanced.png`、`probe-63-20-label-mode-reset.png`、`probe-63-35-reset-after-print.png`、`probe-63-37-after-save-reset.png`、`probe-63-38-shared-reset.png`。

## “立即重置”点按结果

由于按钮在上述所有真实用户状态中均为隐藏控件，无法按用户可见路径点按。工装向隐藏按钮投递一次 `BM_CLICK` 后，“显示数据”仍为 `12345679`，见 `probe-63-after-immediate-reset-values.txt`；该结果不能证明用户可见语义，只证明隐藏态点击不生效。

## 三态结论

**原版有但受限。** 原版资源和控件树确有“重置初始值:”与“立即重置”，但在本机未激活标准版、专业版演示模式及上述状态组合中始终隐藏，用户无法操作。帮助页 `datasource_type_serial.html` 与 `label_object_page_data_serial.html` 只说明序列推进、归位和初始值来源，没有说明这两个隐藏控件。

因此 DIFF-63 继续记为“待取证”，复刻版保持现状，不按猜测增加入口。下一次取证需要一份能让原版重置分组显示的已配置模板，或已连接数据库后的序列号对象；显示后再验证“立即重置”是否立即把主数据源页“显示数据”恢复到哪个值。
