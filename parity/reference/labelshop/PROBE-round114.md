## 二、真机操作要点（可复现）

1. **打开已有模板**：`Ctrl+O` 打开的是**云模板对话框**「打开标签模板」，带「登录后，才能打开标签模板。请先登录！」；
   左下角有「打开本机文件」「打开旧版本文件」。点「打开本机文件」后本机会直接建出新文档（`新标签模板N`）。
   该对话框是**模态**：不关掉它，后面的菜单/画布操作全落到它身上（本轮第一次探测就踩了这个坑）。
   关掉用 `LabelShopCtl -Action run -Steps 'close'`（ESC → WM_CLOSE）。
2. **选对象工具**：`Alt+T` 打开「工具(T)」菜单（截图 `probe-34-tool-menu.png`：选取(S)/条码(B)/文字(T)/线条(L)/斜线(L)/矩形(R)/图片(P)/数据(D)/表格(G) + 放大/缩小/适应宽度/适应高度/适合窗口）。
   菜单弹出后**再发字母键不生效**（`Alt+T` 后发 `t` 菜单仍停在「选取」），要用方向键：
   `keys:%t{DOWN 2}{ENTER}` = 文字工具。
3. **创建对象**：`postdrag:docview|x1,y1|x2,y2` 在文档视图上拖出对象 —— **原版的对象工具就是拖拽创建**，这条路通了。
   创建的窗口/位置由状态栏「⌖ 毫米」读数与属性页「水平/垂直」共同确认。
4. **打开对象属性**：`Alt+Enter`（`keys:%{ENTER}`）→ 「文字属性」多页属性表；
   翻页用 `keydlg:^{TAB}`（页序：数据源 → 字体 → 文本 → 常规）。

## 三、本轮读到的真机真值（证据文件见同目录）

`probe-42-text-props-values.txt`（拖出 (400,300)→(700,400) 的文字对象，属性页「常规」页）：

```
水平(&H):  25.34   垂直(&V): 12.84   旋转(&R): 0°（4 项）   镜像(&M): 无（3 项）
背景(&B):  透明（2 项，默认选中第 2 项）   颜色(&C): 固定颜色（2 项）   图层：默认（1 项）
数据源页：数据源(&S): 常量（7 项）   显示数据(&D): 12345678
```

- 「常规」页字段顺序：`水平(H)` / `垂直(V)` / `水平(W)` / `垂直(T)` / `旋转(R)` / `镜像(M)` / `背景(B)` / `色彩反相(E)` / `位置锁定(L)` / `不打印输出(N)` / `颜色(C)` / 设置颜色 / 对象附加说明(C) / 对象名称标识 / 图层 —— 分组框为 `位置`/`对齐`/`颜色`/`其它`。
- **观察（未收口为差异）**：真机「水平(W)/垂直(T)」两个下拉是 **DISABLED 且 0 项**（单选一个文字对象时如此，Ctrl+A 选中两个对象时同样如此）。
  复刻版把这两个做成可用下拉（保持当前位置/靠左/水平居中/靠右）。帮助 `label_object_page_general.html` 有「水平位置/垂直位置」的记载，
  故先按「真机在本版本/本对象类型下不启用」记录，不改代码；后续若在其它对象类型上看到启用再定夺。

## 四、对既有参考记录的更正

INDEX.md 的「采集限制 1」写着「原版画布与 MFC 工具栏**不响应合成输入**……`postclick:`/`postdbl:` 同样不产生任何效果」，
并据此把 `67-dlg-object-text.png` / `68-dlg-object-barcode.png`（对象属性页）记成**未采集**。本轮更正：

- 画布确实**能**被驱动——用 `postdrag:`（按住拖出矩形，正是对象工具的创建手势）就落下了文字对象，
  说明当时失败的是 `postclick:`/`postdbl:` 这条**单点点击/双击**路径，而不是「画布不接受消息」。
- 配合 `Alt+Enter` 打开对象属性、`keydlg:^{TAB}` 翻页、`Read-LabelShopDialogValues.ps1` 读值，
  **对象属性对话框（67/68）现在可以完整采集**。下一轮起，需求清单里「对象属性 56 条」的真机侧证据就靠这条链路。

## 五、还没拿下的两件事（留给下一轮）

1. **CTRL+拖动到底是复制还是移动**（需求清单第 42 条）：`postdrag` 步骤目前只投递按键/鼠标消息，
   加不了 `MK_CONTROL`（MFC 走 `GetKeyState`，PostMessage 伪造不了异步键状态）。需要给工装加一个
   「先 SendKeys 按住 Ctrl / 或 SendInput 置键态，再 postdrag」的步骤。
2. **原版拖动有没有「对齐参考线」吸附**：需要上面那条通了以后，用「属性页 → 水平/垂直」读回拖动前后的毫米值来判定
   （复刻版有 5px 吸附，原版帮助无此记载）。
