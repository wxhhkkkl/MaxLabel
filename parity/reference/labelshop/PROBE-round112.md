## 1. 「标签格式设置」窗口（1065x948）

公共部分：
- 上部版面预览；预览下方只读文字 `100.00 x 70.00 毫米 [4行 2列]`
- 页签：`打印机` / `页面` / `标签` / `其它`
- 底部按钮：`确定` / `取消` / `帮助`（`应用(A)` 在系统格式下**灰禁**）

### 标签页（`probe-23`）
分组：`标签`（宽度/高度 + 毫米）、`形状`（下拉，值 `圆角矩形`）、`间距`（列距/行距 + 毫米）、
`孔洞`（下拉 + **灰禁的毫米框**）、`行列`（列数/行数 + 微调按钮）；另有 `多行标签` 按钮。

### 打印机页（`probe-25`）
分组：`打印机`（`名称(N)` 下拉 + `设置(S)` / `安装(I)` 按钮）、`输出方式:` 下拉、
复选框 `整页反相打印`、`单页任务模式`（**`镜像输出` 只在标签打印机下出现**，本机页式打印机时不可见）。

### 页面页（`probe-26`）
分组：`纸张尺寸(Z)` 下拉 + `更改标签格式(S)` 按钮 + `手动设置` 按钮 + `纸型(P)` 下拉 +
`尺寸`（宽度(W)/高度(H)/左空(L)/上空(T) + 毫米）+ `纸张颜色` 分组（含按钮）。
**系统格式（本机当前是 `[608053]`）下：宽度/高度/左空/上空四个框全部灰禁**，纸张尺寸下拉仍可用。

### 其它页（`probe-24`）
分组：`打印顺序`（`起始位置(A)` 下拉 + `首选方向(W)` 下拉）、
`打印位置微调`（`左侧(L)` / `顶部(T)` + 毫米）、按钮 `保存自定义格式`（系统格式下**灰禁**）。
