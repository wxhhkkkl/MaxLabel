# LabelShop V6.39 原版行为细节（复刻要点）

按对复刻的重要性排序。每条注明来源截图。所有结论均来自本目录截图与真机控件枚举，非推测；推测项已显式标注。

---

1. **三行工具栏的官方名称是「工具栏 / 格式栏 / 对齐栏」**
   `查看(V)` 菜单里以勾选项列出：`工具栏(T)`、`格式栏(F)`、`对齐栏(A)`、`状态栏(S)`，且四项默认全部勾选。
   来源：`52-editor-menu-view.png`
   → 复刻时应照此命名，而不是自造 "toolbar1/2/3"。

2. **`排列` 与 `账户` 抢同一个加速键 `(A)`，实际 `Alt+A` 落到 `账户`**
   菜单栏文字为 `排列(A)`、`账户(A)`，但 `Alt+A` 打开的是账户菜单；用 `Alt+G`、`Alt+X` 等猜测均无效，只能靠点击菜单栏坐标打开 `排列`。`建议与反馈` 完全没有加速键、也没有可点开的弹出菜单。
   来源：`40-editor.png`、`54-editor-menu-arrange.png`、`59-editor-menu-account.png`
   → 复刻时避免重复加速键；并注意菜单栏第 12 项是纯命令式入口。

3. **状态栏字段顺序固定为 5 段：打印机 / 标签规格 / 数据库状态 / 鼠标位置 / 缩放比例**
   形如 `Microsoft Print to PDF | 100mm x 70mm 圆角8枚/页 20页/盒 | 未使用数据库 | 鼠标位置 | 201%`，
   鼠标在画布上时第 4 段变为 `60.95, 14.60 毫米`（**单位毫米、两位小数、逗号+空格分隔**）。
   来源：`44-statusbar.png`、`40-editor.png`

4. **两处「打印数量」默认值不一致：面板为 1，打印对话框为 8**
   右侧打印面板（`46-right-print-panel.png`）的 `打印数量:` = `1`；
   `Ctrl+P` 打印对话框（`63-dlg-print.png`）的 `打印数量(Q):` = **`8`**（等于该版式的单页枚数 8），`单签拷贝(C):` = `1`。
   → 复刻时不要统一成一个默认值，这是原版的实际行为差异。

5. **未选中任何对象时，「排列」菜单除前两项外全部禁用，三行工具栏几乎全灰**
   `排列` 菜单中 `对齐`/`尺寸`/`间距`/`旋转`（四个子菜单）、`位置锁定`、`移到最前`/`前移`/`后移`/`移到最后` 全部置灰，仅 `组合(G)`/`取消组合(U)` 可点（且这两项在空画布下也灰）。
   `41/42/43` 三张工具栏截图中绝大多数按钮为灰禁用态，第 17 项 `选取` 为橙色高亮的当前工具。
   来源：`54-editor-menu-arrange.png`、`41-toolbar-row1.png`、`43-toolbar-row3.png`

6. **`编辑` 菜单里「剪切」的加速键是 `Shift+Delete`，「删除」是 `Delete`**（不是常见的 Ctrl+X）
   完整键位：`撤销 Ctrl+Z`、`恢复 Ctrl+Y`、`剪切 Shift+Delete`、`复制 Ctrl+C`、`粘贴 Ctrl+V`、`全选 Ctrl+A`、`删除 Delete`、`属性 Alt+Enter`。
   来源：`51-editor-menu-edit.png`
   → 键盘映射表必须照抄，否则复刻体的快捷键行为会和原版不一致。

7. **`文件` 菜单在「无文档（启始页）」与「编辑态」下内容完全不同**
   无文档态只有 7 项：`新建(N)` / `新建条幅飘带` / `打开(Q)...` / `关闭(C)` / `打印设置(R)...` / `最近的文件`(禁用) / `退出(X)`；
   编辑态变成 14 项，新增 `保存(S)`(Ctrl+S)、`另存为(A)...`、`分享(I)...`(禁用)、`打印(P)...`(Ctrl+P)、`打印预览(V)`、`导出打印机指令文件(E)`(禁用)、`标签格式设置(L)...`、`模板属性设置(M)...`。
   → `打印设置(R)` 这一项只在无文档态出现，是典型的"上下文菜单项"。
   来源：`50-editor-menu-file.png`（编辑态）+ 采集过程中的无文档态抓拍

8. **主窗口标题栏内嵌「请登录」入口与版本号**
   标题为 `签赋 LabelShop [ 标准版 - 未激活 ]   V6.39  [请登录 LabelShop] - <文档名>`：
   方括号内是**授权状态**，其后是版本号，再后面还有一个可点的 `[请登录 LabelShop]`。
   来源：`40-editor.png`

9. **`工具` 菜单就是对象工具清单，且「线条」与「斜线」共用加速键 `(L)`**
   顺序：`选取(S)`、`条码(B)`、`文字(T)`、`线条(L)`、`斜线(L)`、`矩形(R)`、`图片(P)`、`数据(D)`、`表格(G)`，分隔线后接 `放大(I)`、`缩小(O)`(Ctrl+-)、`适应宽度`、`适应高度`、`适合窗口(W)`(Ctrl+Alt+0)。
   来源：`53-editor-menu-tools.png`

10. **`标签格式设置` 对话框的页签是 `打印机 / 页面 / 标签 / 其它`，默认停在「标签」页**
    「标签」页字段与默认值：`宽度(W)=100.00 毫米`、`高度(H)=70.00 毫米`、`形状=圆角矩形`、`列距(P)=2.00 毫米`、`行距(L)=2.00 毫米`、`孔洞=无`（单位框灰禁用）、`列数(C)=2`、`行数(R)=4`；预览下方只读行 `100.00 x 70.00 毫米 [4行 2列]`。
    底部按钮 `确定` / `取消` / `帮助`。
    来源：`61-dlg-custom-label.png`

11. **`选择标签格式` 对话框的关键默认值与只读信息**
    只读两行：`纸张：  210 毫米 X 297 毫米`、`标签：  100.00 毫米 X 70.00 毫米`（纸张用整数毫米，标签用两位小数，**同一对话框内两种精度并存**）。
    下拉默认：`打印机(P)=Microsoft Print to PDF`、`标签品牌(B)=京成云马标签（平张标签）`、`标签类型(G)=云马优质打印纸标签`、`标签名称(L)=[608053] 100mm x 70mm 圆角8枚/页 20页/盒`。
    提示语固定为：`提示：如以上列表中没有尺寸适合的标签格式，请点击"自定义"，自行设置标签的尺寸。`
    底部按钮顺序 `选择(Q)` / `自定义(N)` / `取消(C)` / `帮助(H)`，`选择(Q)` 是默认按钮（带高亮边框）。
    来源：`60-dlg-choose-label.png`

12. **`打印` 对话框里 `打印标签边框(E)` 是**禁用**复选框（文字带删除线），其余三个复选项可点**
    分组框顺序为 `打印机` → `打印范围` → `设置`，右侧另有 `选取起始标签`；
    `位置:` 值为 `PORTPROMPT:`（该打印机的端口名，非空值）。
    底部按钮顺序：`预览(V)` / `打印(P)` / `测试打印` / `取消(C)` / `帮助(H)`。
    来源：`63-dlg-print.png`

13. **菜单项名称与对话框标题经常不一致——复刻时必须分别取**
    - 菜单 `选项(O) → 系统选项(C)...`，但对话框标题是 **`系统设置`**
    - 菜单 `文件(F) → 标签格式设置(L)...`，对话框标题也是 `标签格式设置`（这一对是一致的）
    来源：`56-editor-menu-option.png`、`65-dlg-options.png`

14. **`系统设置` 对话框有 5 个页签，控件枚举顺序即真实布局顺序**
    页签：`常规`（当前，内部为独立子对话框）、`语言`、`单位`、`非打印对象`、`其它`。
    「常规」页顺序：`界面语言(L):` → `标尺单位(U):` → ☐`输出非打印对象(P)` → ☐`不选中非打印对象(N)` → ☐`允许运行脚本(S)` → ☐`启动时运行模板向导` → ☐`自动旋转输出页面` → ☐`新建对象后自动打开属性页` → `标签工作区背景颜色：`[色块] [恢复默认]。
    底部 `确定` / `取消` / `帮助`。
    来源：`65-dlg-options.png`

15. **`关于` 对话框含精确版本号与公司信息，是识别构建的依据**
    `签赋 LabelShop [ 标准版 - 未激活 ]  (6.39.2511) 32位`、`产品ID: 未激活`、按钮 `激活`、
    `京成云马（北京）科技有限公司`、链接 `http://www.360Code.com`、
    版权语 `敬告：本计算机程序受著作权法和国际公约的保护，LabelShop 在此授权您可以自由复制和传播本程序的免费版本。`
    来源：`66-dlg-about.png`

16. **右侧打印面板的标题会跟随当前文档名**：`打印 - 新标签模板1`；面板内页签为 `参数设置` / `打印服务器` / `帮助`（帮助也置灰）。
    来源：`46-right-print-panel.png`

17. **左侧「图层」面板结构极简**：标题 `图层` + 图钉 + X；工具按钮 6 个（新建图层/设置/复制图层/删除图层/重命名/图层属性）；列表三列 = 眼睛(可见) + 图层名(`默认`) + 锁。空模板下只有一个「默认」图层。
    来源：`45-left-panel.png`

18. **工具栏第 1 行里 `T` 图标是「文字工具」，不是加粗**——加粗 `B` 在第 2 行（格式栏）。第 1 行的 `条码` 图标下方还有红色小字 `TMKJ`（品牌水印）。
    来源：`41-toolbar-row1.png`、`42-toolbar-row2.png`
    → 别把第 1 行的 `T` 当字形按钮实现。

19. **工具栏第 2 行内容整体靠右**：x≈0~190 全空，字体名/字号两个组合框占 x≈190~450，之后依次为 `B`(加粗) `/`(斜体) `U`(下划线) `A`(字体颜色) `A+▼`(字号)、四个对齐按钮、两个方框图标、一个带表格的页图标。
    来源：`42-toolbar-row2.png`（已按原图坐标 x=490→下拉箭头、x=560→`B`、x=610→`/` 复核）

20. **`窗口` 菜单按序号列出已打开文档并给当前项打勾**：`新建窗口(N)` / 分隔线 / `1 启始页` / `√ 2 新标签模板1`。
    来源：`57-editor-menu-window.png`

21. **`数据库` 菜单的可用性完全由「是否连库」决定**：空模板下 10 项里只有 `设置数据库(D)...` 可点，`定位记录(S)`(Ctrl+F)、`更新数据库`、四条记录导航、`删除数据库(E)` 全灰；状态栏同时显示 `未使用数据库`。
    来源：`55-editor-menu-database.png`、`44-statusbar.png`

21b. **未激活版本会周期性地弹出「登录 LabelShop」模态框**：内容为 `请使用云马科技账号登录服务器，激活 签赋 LabelShop`，含服务器下拉（默认 `360Code.com`）、`输入账号`、`请输入密码`（旁有 `显示密码` 复选框）、复选框 `保存账号和密码`（默认勾选）、`自动登录`（默认勾选）、按钮 `登录` / `忘记密码` / `注册新用户`，下方提示 `当您登录后，您的文档和设置都会处于联机状态` 与复选框 `不再提示`。
    该框会在采集过程中自行弹出（例如打开打印对话框时），必须用 `ESC` 单独关掉，否则后续按键会被它吞掉。
    来源：采集过程中的桌面抓拍（未作为交付截图保留）

22. **`云马通` 是唯一的"纯在线"菜单**：`首页` 可点，`云标签模板库`/`云数据库`/`云图片库`/`云网页库` 因未登录全部置灰；`账户` 菜单里 `登录...` 与 `演示和体验...` 可点，`注销...`/`账号和授权管理...`/`试用管理...` 置灰。
    来源：`59b-editor-menu-cloud.png`、`59-editor-menu-account.png`

23. **推测项（需复核）**：工具栏第 1 行第 25~29 项（约 x=1030~1200 的两个小字形图标、黄底数据图标、双圆柱图标、齿轮页图标）与第 2 行末两个方框图标，因图标仅 16x16 且无 tooltip 文本，其功能语义为**目视推断**，复刻前应另行确认（例如通过 hover tooltip 或资源字符串表）。
    来源：`41-toolbar-row1.png`、`42-toolbar-row2.png`

## 第二批补充（新动作 `btn:` / `listctl:` / `menupick:` 之后）

24. **「打印」对话框里有一整排默认折叠在可视区外的控件，默认文件名叫 `Delete Form`**
    控件枚举（21 个 Button）显示对话框内除了可见的那几个，还有：
    `打印到文件(&F)`、`只打印数据表中当前记录行的数据`、`UTF-8 字符集输出`、`仅单次打印`、
    `Delete Form`(153x52)、`Run`(153x52)、`设置`(分组框, 763x176)、`起始记录(&T)：`(Static) + `(1,2,5-10,30...)` 提示、`启始页码(&N)：`(Static)。
    其中 `Delete Form` / `Run` 是**表单名相关的按钮**（当前表单名即 `Delete Form`），且 `起始记录` 与 `启始页码` 是两套独立的 Edit。
    来源：`63-dlg-print.png` 及同一对话框的 `listctl:Button/Static/Edit/Combo` 枚举
    → 复刻时「打印」对话框不能只做可见的那 5 个按钮；这是第一批只靠截图看不到的部分。

25. **打印对话框的 `打印数量(Q)` 自带一个 ComboBox 而不是纯输入框**（枚举出一个 `ComboBox 123x30` 与 `Edit 80x33` 相邻），说明数量既可输入也可从预设里选。
    来源：`63-dlg-print.png` 的 `listctl:Edit`/`listctl:Combo` 枚举

26. **「高级打印选项」有整两个页签，且两个页签的默认值都指向"关闭/跟随全局"**
    - `页眉页脚` 页：`输出页眉页脚` **默认不勾选**；`使用全局设置` **默认不勾选**；模板默认值 `&D &T &F - &P`；`位置=页面顶部`、`对齐=左齐`、`偏移=0.00 毫米`、`距离=2.00 毫米`、`文字样式=Arial 9.0 正常体`、`启始页码=1`、`自动更新页码` 未勾选；样式管理四个按钮 `导入/导出/新建/移除` 全部禁用。
    - `定位裁切标记` 页：`输出定位裁切标记(M)` **默认不勾选**，但 `使用全局设置` **默认已勾选**（与上一页相反！）；`标记类型=定位和裁切标记`、定位 `标记尺寸=5.00 毫米`、`位置偏移=-5.00 毫米`（**负值**）、`边界距离=2.00 毫米`、裁切 `标记尺寸=5.00 毫米`、`边界距离=2.00 毫米`；`使用倍宽标记线` 未勾选。
    来源：`64a-dlg-adv-print-options.png`、`64b-dlg-adv-print-cropmark.png`
    → 两页的「使用全局设置」默认值相反，复刻时容易做错。

27. **「高级打印选项」的布局是固定坐标、不做动态重排**：把它用 `MoveWindow` 放大到 1600x1400 后，内部控件位置不变，底部按钮行会出现 `应用(&A)` 与 `帮助` **重叠在同一坐标**（(538,794) 与 (539,794)）；恢复原始 630x780 后只剩 `确定`/`取消`/`帮助` 三个。
    来源：`_enum.ps1` 枚举对比（放大态 vs 原始态）
    → 复刻时该对话框应按固定布局实现；也说明**采集时不要靠"放大窗口"来避免裁剪**，应重定位而非缩放。

28. **打印面板里存在一组「电子秤」相关按钮**：主窗口枚举出 `连接`、`皮重`、`设置`、`连接`、`设置`（成对重复，属不同子面板），另有 `更新`、以及记录导航 `|<` `<` `转到` `>` `>|` 和 `上一页`/`下一页`/`查找记录`。
    来源：主窗口 `listctl:Button` 枚举（配合 `46-right-print-panel.png`）
    → 这些在默认空模板下**不可见**（面板未展开/未连库），只有枚举才能看到，是复刻容易漏掉的功能点。

29. **`工具(T) → 数据(D)` 是"选中数据工具"而非打开对话框**：执行 `menupick:td` 后状态栏变为 `就绪`、无任何窗口出现；主窗口内也搜不到任何「数据源」按钮（只有 `数据库` 与 `输入数据` 两个分组框）。
    来源：`75-data-tool.png` + 主窗口 `listctl:数据` 枚举
    → 若复刻要实现"数据源对话框"，入口不在菜单栏级，应在**对象属性**里（本机无法进一步取证，见 INDEX.md 限制 1）。

30. **`use global settings` 这类"禁用整组"的模式在原版里很常见**：`64a` 的「输出页眉页脚」未勾选 → 其下 8 组控件全部禁用；`64b` 的「使用全局设置」已勾选 → 其下全部禁用。判定条件是**父级复选框**，不是数据可用性。
    来源：`64a-dlg-adv-print-options.png`、`64b-dlg-adv-print-cropmark.png`

31. **未激活版本的登录框会周期性"抢焦点"，且默认勾选 `自动登录`/`保存账号和密码`**：该框一出现，之前排队的按键全部失效（会先被它吃掉）。
    来源：`登录 LabelShop` 模态框的 `listctl:Button` 枚举（INDEX.md 有完整字段表）
    → 复刻做自动化测试时要先处理这个模态框。
