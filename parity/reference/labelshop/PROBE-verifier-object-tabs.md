## 二、与复刻版的差异（`app/src/renderer/src/features/object-properties/propertyTabs.ts`）

| 对象 | 真机 | 复刻版 | 差异 |
| --- | --- | --- | --- |
| 文字 | 数据源 / 字体 / 文本 / 常规 | 通用 / 文字 / 字体 / 数据 | 命名（常规↔通用、文本↔文字、数据源↔数据）+ 顺序全不同 |
| 条码 | 数据源 / 条码 / 字体 / 常规（**4 页**） | 通用 / 条码 / 字体 / 数据 / `<码制>`（**5 页**） | 同上，**并且多出一个「码制专页」页签** |
| 矩形/椭圆/直线 | 图形 / 常规 | 通用 / 方框和圆形（直线为 直线和斜线） | 命名与顺序都不同 |
| 表格 | 表格 / 常规 | 通用 / 表格 | 顺序不同（真机 `表格` 在前、`常规` 在后） |

补充：真机里**没有**名为「方框和圆形」的窗口/页签——本轮 `dump:方框和圆形` 步骤没有匹配到任何窗口（`probe-verifier-11-rect-pages.txt` 未生成），
说明这个名字只存在于帮助页标题，不是 UI 文案。

## 三、顺带取证：真机「工具」菜单的项与顺序（`verifier-tools-menu.png`）

```
1 选取(S)   2 条码(B)   3 文字(T)   4 线条(L)   5 斜线(L)
6 矩形(R)   7 图片(P)   8 数据(D)   9 表格(G)
──────────
放大(I)  缩小(O) Ctrl+-  适应宽度  适应高度  适合窗口(W) Ctrl+Alt+0
```

**真机工具菜单里没有「RFID」** —— 复刻版工具栏/菜单有 RFID 工具，需要核对原版的 RFID 对象创建入口
（是 `数据(D)`？还是别的菜单/对话框），不能凭帮助页保留一个原版可能没有的工具入口。

## 四、工装坑（本轮踩到，已可复用）

1. **有模态对话框时不能用 `keys:`**：`keys:` 会把**主窗口**置前再 SendKeys，模态对话框会因此收不到键
   （实测：冷启动后对着「模板向导」发 `keys:{ENTER}` 两步都没反应，向导停在第一页）。
   正确做法：对话框上用 **`keydlg:`**（它先把最上层对话框置前），编辑态再用 `keys:`。
2. MFC 弹出菜单要抓 `shotpopup:`（屏幕抓取拍不到该窗口）；菜单项顺序就是靠它拿到的。
3. 真机取证与 clone 的 UI 门禁**不冲突**（UI 脚本不做 OS 级截图，实测 `captureScreenshot` 仅 3 处、
   无 `screenshot-desktop/copyFromScreen`），可以并行。
