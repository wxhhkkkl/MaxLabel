## 四、工装坑（本轮踩到，已可复用）

1. **有模态对话框时不能用 `keys:`**：`keys:` 会把**主窗口**置前再 SendKeys，模态对话框会因此收不到键
   （实测：冷启动后对着「模板向导」发 `keys:{ENTER}` 两步都没反应，向导停在第一页）。
   正确做法：对话框上用 **`keydlg:`**（它先把最上层对话框置前），编辑态再用 `keys:`。
2. MFC 弹出菜单要抓 `shotpopup:`（屏幕抓取拍不到该窗口）；菜单项顺序就是靠它拿到的。
3. 真机取证与 clone 的 UI 门禁**不冲突**（UI 脚本不做 OS 级截图，实测 `captureScreenshot` 仅 3 处、
   无 `screenshot-desktop/copyFromScreen`），可以并行。

## 五、追加取证（round-6）：**码制选择就在「条码」页内**，没有第 5 个页签

`verifier-20c-barcode-page.png`（真机 条码属性 → 第 2 个页签「条码」，Code 128）实测字段与分区：

| 分区 | 字段（原文） | 值/默认 |
| --- | --- | --- |
| —（页首） | **条码符号类型(码制)(B):** | `Code 128`（下拉，**就在这里选码制**） |
| 尺寸 | **X 尺寸(X):** | `10.00 mil`（下拉） |
| 尺寸 | **码高(H):** | `10.00 毫米`（数字 + 上下箭头） |
| 条码特殊选项 | `GS1/EAN 128(U)` 复选框、**字符集(C):** | `自动`（下拉）——**本组内容随所选码制变化**，这就是"码制专属选项" |
| 供人识读字符 | **位置(P):** / **垂直偏移(O):** / **对齐方式(A):** / `字符模板(I)` | `条码下方` / `0.00 毫米` / `居中` / 未勾选 |
| ~~—（页尾）~~ | ~~**颜色:**~~ | **❌ 本行已作废（round-113 定案）**：真机「条码」页**没有颜色控件**（该页共 8 个控件，见 `PROBE-round113-barcode-page.md`）；颜色在**「常规」页**，原文 `颜色(&C):`（值域本机只有 `固定颜色`）。复刻版已按此把「条码颜色」迁到常规页并改名，见 DIFF-72。 |

**结论**：真机条码属性**只有 4 个页签**，`码制` 选择器与"随码制变化的专属字段"都在**「条码」页内**（专属字段放在「条码特殊选项」分组里）。
所以复刻版把码制拆成第 5 个页签 `Code128/ITF14/…` 是**结构性偏差**（DIFF-64 ⑤）：
正确形态 = 4 页签 + 条码页顶部放码制下拉 + 「条码特殊选项」分组随码制切换内容。

## 六、追加取证（round-6）：`数据(D)` 工具建出来的是**条码对象**，RFID 仍无入口

工具菜单第 8 项 `数据(D)` 拖出的对象，`Alt+Enter` 打开后 `listctl` 报根窗口标题＝**「条码属性」**（37 个控件），
即 `数据(D)` 建的是"数据型条码对象"，不是 RFID。加上 round-5 的工具菜单实测（1选取 2条码 3文字 4线条 5斜线 6矩形 7图片 8数据 9表格），
**真机工具菜单及其可达路径里都没有 RFID 对象入口**（DIFF-65 的候选已排除 `数据(D)`）。
