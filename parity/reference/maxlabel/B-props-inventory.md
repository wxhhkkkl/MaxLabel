# 对象属性页 全量盘点（验收方 CDP 实测）

来源：`tools/parity/scenarios/props-inventory.json`（对 7 种对象逐一「工具→画布创建→Alt+Enter」）
截图：`parity/reference/maxlabel/B-inventory-final.png`

| 对象类型 | 页签（顺序） | 该类型特有字段 |
| --- | --- | --- |
| 文字 | 通用 / 文字 / 字体 / 数据 | 文字类型、水平对齐（左/居中/右/撑满）、文字停靠、行宽度、垂直对齐、行距、圆形参数、字符模板 |
| 条码 | 通用 / 条码 / 字体 / 数据 / **当前码制专页**（如 `Code128`） | 码制、X 尺寸(mil)、宽条比例、各码制特殊选项、人读字符位置/垂直偏移/对齐 |
| 矩形 | 通用 / **方框和圆形** | 形状、圆角半径、线宽（mm）、填充方框内部、颜色变化模式 |
| 线条 | 通用 / **直线和斜线** | 线宽（mm） |
| 图片 | 通用 / 图片 / 数据 | 类型（嵌入/链接/数据源图片）、图片目录、缩放方式、保持长宽比、宽高百分比、对齐方式（9） |
| 表格 | 通用 / 表格 | 表格专属参数 |
| RFID | 通用 / RFID / 数据 | 读写器类型、数据段位置、起始块位置、数据类型、PC 协议控制字、编码码头/长度、访问控制 5 组、Access/Kill 口令 + 随机生成 |

## 通用页（`label_object_page_general.html`）字段与选项（实测）
- `水平位置`：`（保持当前位置）| 靠左 | 水平居中 | 靠右`
- `垂直位置`：`（保持当前位置）| 靠顶 | 垂直居中 | 靠底`
- `X（毫米）`、`Y（毫米）`、`宽度（毫米）`、`高度（毫米）`（数值输入）
- `旋转（度）`：`0 | 90 | 180 | 270`
- `对象附加说明`
- `背景`：`不透明 | 透明`
- `打印时可见`、`不打印输出`、`位置锁定`（复选框）
- `镜像`：`无 | 水平镜像 | 垂直镜像 | 水平+垂直镜像`
- `颜色变化模式`：`固定颜色 | 颜色索引表 | 颜色变量`（文字/矩形有；线条/图片/表格/RFID 无）
