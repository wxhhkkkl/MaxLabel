| 对象的颜色 → 颜色表示方式、索引表类型、变化模式与索引值算法 | 签赋LabelShop支持对象可变颜色打印，即文字、条码对象的颜色是可变的，包括每个字符的颜色可以不同、条码可以由多个颜色块组成、连续打印多个标签时同一对象在不同的标签上颜色可以变化；文字、条码、直线、矩形和图片都可以设置可变颜色打印属性，其中图片只有单色的黑白图片支持可变颜色；颜色可以用两种方式表示：颜色索引（支持文档模板公共颜色索引和对象私有颜色索引表，颜色索引表包括十个预先定义的颜色，分别对应索引0到9）和颜色值（直接使用RGB值，要求使用"#FF0000"样式的十六进制颜色值表示，多个颜色数值需要使用半角逗号或者竖线分隔开）；颜色索引表分为模板公共颜色索引表（在所有对象中一致）和对象私有颜色索引表（仅对当前对象有效）；颜色变化模式有随机颜色（颜色随机产生）、以数据源内容为索引（文字和条码对象按内容为索引并使用索引颜色表，其它对象使用索引为0的颜色）、颜色索引变量（以标签模板上一个命名变量的值为颜色索引值）、颜色值变量（以命名变量的值为颜色RGB值）、颜色索引（以输入的内容做为颜色索引）、RGB颜色值（以输入的内容做为颜色RGB值）；颜色索引值计算方法为数字0至9以数字本身做为颜色索引，字母A至Z以（字母的内码-A)Mod 10做为颜色索引，字母a至z以（字母的内码-A)Mod 10做为颜色索引，其它字符以字符内码mod 10做为颜色索引；对于直线、矩形和图片对象颜色是整体变化的，对于文字对象可以选择整体变色或者每个字符变色两种方式，对于条码对象可以选择整体变色、按行列（区块）变色以及渐变变色方式 | color_main.html | 待核 |  |

| 对象的颜色 → 各颜色模式下的取值规则与命名变量放置 | 在随机颜色模式下每个对象的颜色会在打印时随机设置；在以数据源内容为索引颜色模式下，将以对象的内容为索引并使用索引表中的颜色，对于直线、矩形和图片对象默认其内容为0、使用索引值为0的颜色，对于文字和条码对象则使用其内容的字符做为颜色索引，当这两类对象使用整体变色方式时取内容的第一个字符计算索引值，当使用每个字符变色或者区块变色方式时则取内容的每个字符的值计算颜色索引值；在颜色索引变量或者颜色索引模式下，需要选择一个命名变量或者输入的内容做为颜色索引值，对于直线、矩形和图片对象以及整体变色的条码和文字对象，以变量值的第一个字符计算颜色索引值，对于按每个字符变色的文字对象和按区块变色的条码对象则依次循环使用变量值的每个字符计算颜色索引值；在颜色值变量和RGB颜色值模式下，需要选择一个命名变量的值或者输入的内容做为颜色的数值，颜色数值是采用十六进制表示的RGB颜色值，多个颜色数值需要使用半角逗号或者竖线分隔开，对于直线、矩形和图片对象以及整体变色的条码和文字对象使用变量值的第一个索引值，对于按每个字符变色的文字对象和按区块变色的条码对象则依次循环使用变量值的每个颜色值；签赋LabelShop中的命名变量必需包含在的一个对象中，对于只用于表示颜色索引或者颜色值的变量，可以使用一个文字对象包含这个变量，并将这个文字对象放置在标签的外面，完全位于标签外部的对象不会被打印输出，但其中包含的命令变量值可以在颜色定义中被引用 | color_main.html | 待核 |  |
