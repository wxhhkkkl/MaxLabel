=== label_object_page_rfid.html === TITLE: RFID标记对象属性
RFID标记对象是指RFID标签内容。签赋LabelShop 可以在一个标签模板中排入多个RFID对象。
RFID标记对象支持以下特性：
数据源
RFID对象的数据可以是多种类型，包括常量数据、序列号、数据库字段等，并且可以是由多段数据组合连接而成。同时，数据可能需要在输出前进行补齐长度、删除多余字符等特殊处理。签赋LabelShop
强大的数据处理功能可以满足要求。详情请参考 对象的数据源 章节。
特别说明：
RFID标记数据默认是16进制类型，错误使用数据源，将无法正确打印输出。
RFID
用于配置RFID标记主体。
读写器类型： 选择RFID读写器协议。
数据段位置： 选择EPC区、USER用户区和TID区数据段。
起始块位置： 选择数据段后，可配置起始块位置。
数据类型： 选择十六进制或ASCII码值数据类型。
EPC区PC协议控制字设置： 配置ISO1800-6C协议PC值和国标/军标协议编码码头及编码长度。
访问控制
EPC Block： EPC区的锁定与解锁
User Block： User用户区的锁定与解锁。
TID Block： TID区的锁定与解锁。
Access Password： 访问口令的锁定与解锁。
Kill Password： 灭活口令的锁定与解锁。
Access Password
配合访问控制，设置新访问口令，可随机生成
Kill Password
配合访问控制，设置新灭活口令，可随机生成
