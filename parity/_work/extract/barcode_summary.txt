=== barcode_summary.html === TITLE: 条码码制
商品条码
EAN码/UPC码：国际物品编码协会在全球推广的商品条码。EAN-13是其标准版，有13位；另有缩短版EAN-8，8位。UPC码主要用于美国和加拿大地区。UPC-A是其标准版，有12位；另有缩短版UPC-E，7位。EAN13是国际通用的符号体系，是一种无含义、定长、纯数字的条形码，主要用于商品标识。中国的商品以690-699开头，后面是厂商识别码为和商品项目代码，最后一位是校验字符。
Code 39
Code 39码：是Intermec公司于1974年发明的条码码制，是世界上最为广泛使用的条码码制之一，尤其是非零售行业。Code 39码可表示数字、英文字母以及“-”、“.”、“/”、“+”、“%”、“$”、“ ”（空格）和“*”共44个符号，其中“*”仅作为启始符和终止符，仅有两种单元宽度。 美国国防部和汽车行业最先使用Code39码，且有编码规则简单、误码率低、所能表示字符个数多等特点，因此在各个领域有着极为广泛的应用。我国也制定了相应的国家标准（GB12908-2002）。主要应用于企业内部管理，像工业生产线领域、图书管理、快递物流、仓库管理、零售批发和产品标识等等。
Code 128
Code 128码：是1981年引入的一种高密度条码，可表示从 ASCII 0 到ASCII 127 共128个字符，故称128码。其中包含了数字、字母和符号字符；广泛应用在企业内部管理、生产流程、物流控制系统方面的条码码制，由于其优良的特性在管理信息系统的设计中被广泛使用，CODE128码是当今应用最广泛的条码码制之一。
Code 128码与Code 39码有很多的相近性，都广泛运用在企业内部管理、生产流程、物流控制系统方面。不同的在于Code 128比Code 39能表现更多的字符，单位长度里的编码密度更高。当单位长度里不能容下Code 39编码或编码字符超出了Code 39的限制时，就可选择Code 128来编码。所以Code 128比Code 39更具灵性，但是相对来说Code 39具有更好的试读性。
Interleaved 25
交叉25码：主要应用于商品批发、仓库、机场、生产/包装识别、工业中 条形码的识读率高，可适用于固定条码扫描器可靠扫描， 在所有一维条形码中的密度较高。同其它码相比，如果标签大小以及位数相同，交叉25码的窄条宽度更宽。因此即使打印机的打印质量不好。也可以打印交叉25码。不仅如此，更宽的窄条可以允许从远距离读取条码。
ITF 14
ITF 14码：条码字符集、条码字符的组成与交插二五码相同。具有连续型、定长、自带校验功能，并且条、空都表示信息的双向条码。它由矩形保护框、左侧空白区、条码字符、右侧空白区组成。主要用于商品运输包装上，标识非零售的商品。对印刷或打印要求不高，比较适合直接印制（热转印或喷墨）于表面不够光滑、受力后尺寸易变形的包装材料，如瓦楞纸或纤维板上。保护框就是用来防止打印压力直接集中在条码上并保持均匀的打印压力。
Codebar
Codabar码：可表示数字0 - 9,字符$、+、 -、还有只能用作起始/终止符的a, b, c d四个字符。空白区比窄条宽10倍 非连续性条形码，每个字符表示为4条3空。可变长度，没有校验位，主要应用于物料管理、图书馆、血库血站和当前的机场包裹发送跟踪管理。
PDF417
PDF417码：是由留美华人王寅敬（音）博士发明的。PDF是取英文Portable Data File三个单词的首字母的缩写，意为“便携数据文件”。因为组成条码的每一符号字符都是由4个条和4个空构成，如果将组成条码的最窄条或空称为一个模块，则上述的4个条和4个空的总模块数一定为17，所以称417码或PDF417码。自Symbol公司1991年将PDF417作为公开的系统标准后，PDF417条码为越来越多的标准化机构所接受。本身可存储大量数据应用于：医院、驾驶证、物料管理、货物运输 当条形码受一定破坏时，错误纠正能使条形码能正确解码。
QR Code
QR码：是由日本Denso公司于1994年9月研制的一种矩阵二维码符号，呈正方形，常见的是黑白两色。在3个角落，印有较小，像“回”字的的正方图案。这3个是帮助解码软件定位的图案，用户不需要对准，无论以任何角度扫描，数据仍可正确被读取。它具有信息容量大、超高速识读、全方位识读、可靠性高、可表示汉字及图象多种文字信息、保密防伪性强和抗损毁能力等优点。容量密度大，可以放入1817个汉字、7089个数字、4200个英文字母。表层应用多见于发票、车票，简单的资讯型应用；深层应用多见于验证、防伪、追溯、签到、军事、更多能交互信息的商业应用服务上。
Data Matrix
Data Matrix码：可编码字符集包括全部的ASCII字元及扩充ASCII字元，共256个字元。尺寸可任意调整，最大可到14平方英寸，最小可到0.0002平方英寸，这个尺寸也是目前一维与二维条码中最小的，同时只需要读取资料的20%即可精确辨读。因此特别适合在条码容易受损的场所，例如印在暴露於高热、化学清洁剂、机械剥蚀等特殊环境的电路版、机械零件、药品等小件物品上。另一方面，大多数的条码的大小与编入的资料量有绝对的关系，但是Data Matrix二维条码的尺寸与其编入的资料量却是相互独立的，因此它的尺寸比较有弹性。 此外，DataMatrix二维条码最大储存量为2,000bytes，自动纠正错误的能力较低。
汉信码
汉信码：是我国第一个制定了国家标准并且拥有自主知识产权的二维码。在汉字信息表示方面汉信码达到国际领先水平，还具有极高的二进制数据等信息的编码效率、符号信息密度与容量大、识读速度快、纠错及抗污损变形能力强等特点。同时支持英文、日文、德文、阿拉伯文、希伯来文等全系列语言文字高效编码的码制，能够实现针对多国文字的自适应高效编码。最多可以表示7829个数字、4350个ASCII字符、2174个汉字、3262个8位字节信息，支持照片、指纹、掌纹、签字、声音、文字等数字化信息的编码。
