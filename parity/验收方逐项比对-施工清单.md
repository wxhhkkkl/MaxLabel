## 复跑方式（验收方）

```powershell
# 1) 从某个提交构建并抓图（隔离克隆，不碰主仓库 node_modules ✓）
powershell -File tools/parity/Shoot-FromCommit.ps1 -Sha HEAD -Scenes 'choose,custom,sysset,printerportbox,printdialog'
# 2) 与真机图并排（右标签写 commit SHA ✓）
powershell -File tools/parity/Compare-SideBySide.ps1 -Left <真机图> -Right <复刻图> -Out <并排图> -LabelLeft <真机说明> -LabelRight "复刻版 MaxLabel（commit <sha>）"
# 3) 打印链路端到端（A4 一旦落地就会转绿 ✓）
node tools/parity/Verify-PrintEndToEnd.cjs
```
