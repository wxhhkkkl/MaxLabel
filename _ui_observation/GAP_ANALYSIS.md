## 3. 当前交互操作实现状态

### 3.1 双击文字编辑

**未实现。**

- `LabelEditor.tsx` 第 33-58 行：文字对象使用 `fabric.Text`（静态文本），而非 `fabric.IText` 或 `fabric.Textbox`（可编辑文本）。
- 代码中无 `mouse:dblclick` 事件监听，无 `enterEditing` 调用。
- LabelShop 规范（`label_object_modify.html`）："在选定的对象上双击鼠标左键或选中属性菜单命令，会出现属性对话框"——即双击对象应弹出属性对话框，而非直接内联编辑文字。
- 当前 MaxLabel 的属性编辑通过右侧 `PropertyPanel.tsx` 面板完成（选中对象后自动显示），但**双击无任何响应**。

**差距**：
1. 双击对象应弹出属性对话框（LabelShop 规范）或进入文字内联编辑（现代编辑器惯例）。
2. 文字对象使用 `fabric.Text` 而非 `IText`，即使想做内联编辑也需要先替换类型。

### 3.2 对象选中句柄

**使用 Fabric.js v6 默认样式，未做自定义。**

- `LabelEditor.tsx` 第 336-340 行：创建 `fabric.Canvas` 时未设置 `selectionColor`、`selectionBorderColor`、`selectionLineWidth`、`transparentCorners`、`cornerColor`、`cornerStrokeColor`、`cornerSize`、`rotatingPointOffset` 等控制属性。
- Fabric v6 默认：8 个方形控制点（四角 + 四边中点），白色填充 + 蓝色边框，顶部有旋转手柄（带连接线）。
- LabelShop 规范（`label_object_align_align.html`）："参考对象是对齐操作的基准，参考对象总是很容易被识别，它有**蓝色的实心句柄**，而同一组中的其它对象只有**黑色的实心句柄**"——即多选时参考对象（第一个选中的）用蓝色句柄，其他对象用黑色句柄。
- 当前 MaxLabel：多选时所有对象句柄样式一致（Fabric 默认），**无参考对象蓝色句柄区分**。

**差距**：
1. 未自定义句柄样式（LabelShop 为实心方块，颜色区分参考对象）。
2. 多选时无参考对象（蓝色句柄）与普通对象（黑色句柄）的视觉区分。
3. 旋转手柄存在（Fabric 默认），但未自定义偏移量和样式。

### 3.3 多选

**部分实现。**

- **框选（拖拽选择）**：`LabelEditor.tsx` 第 337 行 `selection: true`，Fabric 默认支持在画布空白处拖拽出选框进行多选。但在非选择工具模式下（`tool !== 'select'`），第 410 行 `fc.selection = !drawing` 会禁用框选。
- **Ctrl+点击 / Shift+点击**：未显式实现。Fabric.js 默认支持 Shift+点击追加选中，但代码中未做特殊处理。`App.tsx` 第 533 行 `handleGroup` 的提示文字写的是"按住 Shift 多选或全选"，说明预期 Shift+点击可用，但未在代码中显式绑定或验证。
- **Ctrl+A 全选**：`App.tsx` 第 301-309 行 `selectAll` 函数已实现（通过菜单触发），但**无键盘快捷键绑定**。
- **TAB / CTRL+T 依次选中**：LabelShop 规范（`label_object_select_key.html`）支持 TAB 键依次选中对象，当前未实现。

**差距**：
1. 无键盘快捷键触发全选（CTRL+A）。
2. 无 TAB/CTRL+T 循环选中。
3. Shift+点击依赖 Fabric 默认行为，未显式确认和定制。

### 3.4 快捷键

**完全未实现（0 个）。**

全局搜索确认无任何 `keydown`/`keyup` 事件监听器。LabelShop 规范中的所有快捷键均缺失，详见第 4.3 节。

### 3.5 拖拽移动

**使用 Fabric.js 默认行为，无自定义视觉反馈。**

- 拖拽移动：Fabric 默认支持，对象跟随鼠标实时移动。
- 无拖拽时的半透明幽灵效果（ghost）或轮廓线（outline）反馈。
- 无对齐辅助线（snap guide / smart guide）——拖拽对象时 LabelShop 会显示对齐辅助线。
- 无位置锁定功能——LabelShop 支持锁定对象位置（`label_object_align_pos.html`："位置被锁定的对象不能被移动"），当前模型 `BaseObj` 中无 `locked` 字段，排列菜单中也无"锁定"项。
- 键盘微调移动（方向键）：未实现。LabelShop 规范（`label_object_move_key.html`）支持 UP/DOWN/LEFT/RIGHT 键移动选中对象。

**差距**：
1. 无拖拽视觉反馈（幽灵/轮廓）。
2. 无对齐辅助线（smart guides）。
3. 无对象位置锁定。
4. 无方向键微调移动。

## 5. 优先级差距清单（Top 20）

按"复刻价值高 + 实现难度低"排序。复刻价值 = 对 LabelShop 用户体验还原度的贡献；实现难度 = 基于现有代码架构的改造成本估算。

### 第一梯队：快捷键体系（高价值 + 低难度）

#### 1. 全局键盘快捷键绑定
- **差距描述**：当前 0 个快捷键，LabelShop 有 30 个标准快捷键。这是最影响操作效率的差距。
- **涉及文件**：`App.tsx`（新增 `useEffect` 监听 `keydown`）、`MenuBar.tsx`（`MenuItem` 接口新增 `shortcut` 字段并在右侧渲染）
- **建议修改方向**：在 `App.tsx` 中添加全局 `keydown` 事件监听，优先实现最高频的 15 个：CTRL+N/O/S/W/P/Z/Y/A/C/V/X、DELETE、CTRL+G/U、F1。同时在 `MenuItem` 接口加 `shortcut?: string`，菜单渲染时右侧显示快捷键文本。

#### 2. 方向键微调移动对象
- **差距描述**：LabelShop 支持 UP/DOWN/LEFT/RIGHT 键移动选中对象，当前完全不支持。
- **涉及文件**：`App.tsx`（keydown 监听中调用 `updateObject` 修改 x/y）
- **建议修改方向**：在全局 keydown 中，当有选中对象且焦点不在输入框时，方向键每次移动 0.5mm（或 1mm），Shift+方向键移动更大步长（如 5mm）。直接调用已有的 `updateObject(selectedObj.id, { x: ... })`。

#### 3. DELETE 键删除选中对象
- **差距描述**：LabelShop 按 DELETE 键删除选中对象，当前不支持（只能通过菜单/工具栏按钮）。
- **涉及文件**：`App.tsx`（keydown 监听）
- **建议修改方向**：全局 keydown 中监听 `Delete`/`Backspace`，当有选中对象且焦点不在输入框时调用 `deleteObject(selectedObj.id)`。注意避免在文本输入框中误触发。

### 第二梯队：右键菜单（高价值 + 中低难度）

#### 4. 画布对象右键菜单
- **差距描述**：LabelShop 右键菜单包含约 40 个菜单项（属性/组合/锁定/对齐/尺寸/旋转/层次/剪贴板/导出/显示/标签旋转），当前完全没有右键菜单。
- **涉及文件**：`LabelEditor.tsx`（绑定 `mouse:down` 检查 `e.button === 2` 或 canvas `contextmenu` 事件）、新增 `ContextMenu.tsx` 组件
- **建议修改方向**：先实现核心子集（剪切/复制/粘贴/删除/全选/属性/组合/取消组合/锁定/对齐6项/旋转3项/移到最前/最后），复用 `MenuBar.tsx` 的下拉渲染逻辑或新建轻量 ContextMenu 组件。在 Fabric canvas 上监听 `contextmenu` 事件，`preventDefault` 后在鼠标位置弹出菜单。

#### 5. 图层面板右键菜单
- **差距描述**：LabelShop 图层面板项支持右键操作，当前仅有行内按钮。
- **涉及文件**：`LayerPanel.tsx`
- **建议修改方向**：在图层行上添加 `onContextMenu`，弹出菜单（删除/重命名/上移/下移/置顶/置底/显示/隐藏/锁定）。可与画布右键菜单复用同一 ContextMenu 组件。

#### 6. 标签页右键菜单
- **差距描述**：LabelShop 标签页支持右键（关闭/关闭其他/关闭所有/新建），当前仅有左键切换和关闭按钮。
- **涉及文件**：`TabStrip.tsx`
- **建议修改方向**：在标签页上添加 `onContextMenu`，弹出"关闭/关闭其他标签/关闭所有标签/新建标签"菜单。

### 第三梯队：交互体验（高价值 + 中难度）

#### 7. 双击对象弹出属性对话框
- **差距描述**：LabelShop 双击对象弹出属性对话框，当前双击无任何响应。
- **涉及文件**：`LabelEditor.tsx`（监听 `mouse:dblclick`）、`App.tsx`（新增属性对话框状态）
- **建议修改方向**：在 Fabric canvas 上监听 `mouse:dblclick`，若点击在对象上则触发 `onDoubleClick(id)` 回调，在 App 中弹出属性对话框（可复用 `PropertyPanel` 的内容包装为 Modal，或先简单地将右侧属性面板滚动到可见并高亮）。

#### 8. 对象创建改为拖拽绘制
- **差距描述**：LabelShop 选择工具后按住左键拖拽绘制自定义大小对象，当前是单击放置固定大小（40×8mm）对象。
- **涉及文件**：`LabelEditor.tsx`（`mouse:down` 记录起点，`mouse:move` 更新临时对象，`mouse:up` 完成创建）、`App.tsx`（`onCreateAt` 改为 `onCreateRect`）
- **建议修改方向**：在非选择工具模式下，`mouse:down` 时创建一个临时 Fabric 对象（半透明），`mouse:move` 时更新其宽高，`mouse:up` 时调用 `onCreateAt(type, x, y, w, h)` 创建最终对象。这是更符合 LabelShop 体验的创建方式。

#### 9. 多选时参考对象蓝色句柄区分
- **差距描述**：LabelShop 多选时第一个选中的对象（参考对象）用蓝色实心句柄，其他用黑色实心句柄，当前所有对象句柄样式一致。
- **涉及文件**：`LabelEditor.tsx`（自定义 Fabric 控件样式）
- **建议修改方向**：在 `selection:created`/`selection:updated` 事件中，遍历选中对象，对第一个（参考对象）设置 `cornerColor: '#1E90FF'`，其他设置 `cornerColor: '#000000'`，并统一设置 `transparentCorners: false`（实心句柄）、`cornerSize: 8`、`cornerStrokeColor: 'transparent'`。

#### 10. 自定义选中句柄样式（实心方块）
- **差距描述**：LabelShop 使用实心方块句柄，当前使用 Fabric 默认（白色填充+蓝色边框的方形句柄）。
- **涉及文件**：`LabelEditor.tsx`（canvas 初始化时设置全局控件样式）
- **建议修改方向**：在 `new fabric.Canvas()` 后设置全局默认：`fabric.Object.prototype.set({ transparentCorners: false, cornerColor: '#1E90FF', cornerStrokeColor: '#1E90FF', cornerSize: 8, borderColor: '#1E90FF', borderScaleFactor: 1, rotatingPointOffset: 20 })`。

#### 11. 对象位置锁定功能
- **差距描述**：LabelShop 支持锁定/解除锁定对象位置（CTRL+L），锁定后对象不能移动、对齐命令无效，当前完全不支持。
- **涉及文件**：`shared/model.ts`（`BaseObj` 新增 `locked?: boolean`）、`LabelEditor.tsx`（创建对象时设置 `lockMovementX/Y`）、`App.tsx`（排列菜单新增"锁定"项、handleAlign/handleDist 中跳过锁定对象）
- **建议修改方向**：在模型中加 `locked` 字段，渲染时若 `locked` 为 true 则设置 Fabric 对象 `lockMovementX = true, lockMovementY = true`。对齐/间距/居中操作中过滤掉锁定对象。排列菜单和右键菜单中添加"锁定/解除锁定"切换项。

### 第四梯队：菜单补全（中价值 + 低难度）

#### 12. 文件菜单补全：关闭、最近文档
- **差距描述**：LabelShop 文件菜单有"关闭"（CTRL+W）和"最近文档"子菜单，当前缺失。

#### 14. 查看菜单补全：标签旋转子菜单
- **差距描述**：LabelShop 查看菜单有"标签旋转"子菜单（正常显示/左旋90度/右旋90度/旋转180度），用于旋转整个标签板面显示，当前缺失。
- **涉及文件**：`App.tsx`（menuSections 查看菜单 + 新增 labelRotation 状态）、`WorkArea.tsx`（根据旋转角度旋转画布容器）
- **建议修改方向**：新增 `labelRotation` 状态（0/90/180/270），在 `WorkArea` 中对画布容器应用 CSS `transform: rotate()`。查看菜单添加"标签旋转"子菜单。这与对象旋转不同，是纯显示层面的版面旋转。

#### 15. 数据库菜单补全：记录导航项

- **涉及文件**：`App.tsx`（menuSections 数据库菜单）
- **建议修改方向**：记录导航功能在工具栏（`Toolbar.tsx`）已有按钮和对应处理函数（`setRecord`、`handleDbRefresh`），直接在菜单中复用这些函数即可。添加"定位记录"（CTRL+F，可先简单实现为输入框跳转）、"更新数据库"、四个记录导航项。

#### 16. 工具菜单结构调整：对象工具改为直接菜单项
- **差距描述**：LabelShop 工具菜单中条码/文字/线条等是直接并列菜单项，当前收进了"添加对象"二级子菜单，多了一次点击。
- **涉及文件**：`App.tsx`（menuSections 工具菜单）

### 第五梯队：视觉与细节（中价值 + 中难度）

#### 17. 鼠标滚轮缩放画布

- **涉及文件**：`WorkArea.tsx` 或 `LabelEditor.tsx`（监听 `wheel` 事件）
- **建议修改方向**：在画布容器上监听 `wheel` 事件，`preventDefault` 后根据 `deltaY` 调整 zoom（以鼠标位置为中心缩放更佳，但简单实现可直接调 `setZoom`）。缩放级别复用已有的 `ZOOM_LEVELS`。

#### 18. 空格键拖动画布（平移）
- **差距描述**：LabelShop 支持按住空格键+鼠标左键拖动画布平移，当前不支持。
- **涉及文件**：`WorkArea.tsx`（监听空格 keydown/keyup + 鼠标拖拽）
- **建议修改方向**：空格键按下时将画布容器光标改为 `grab`，记录鼠标起始位置和滚动位置，鼠标移动时更新 `scrollLeft`/`scrollTop`。空格键释放时恢复。这是大型画布编辑的标准交互。

- **涉及文件**：`StatusBar.tsx`（新增对象信息显示）、`App.tsx`（传入 selectedObj）
- **建议修改方向**：`StatusBar` 新增 `objInfo` prop，当有选中对象时显示"X: xx.xx mm, Y: xx.xx mm, W: xx.xx mm, H: xx.xx mm"，无选中时显示光标坐标。参考 `toolbar_status.html` 规范。

#### 20. 图层面板顶部工具栏
- **差距描述**：LabelShop 图层面板顶部有工具栏图标（新建/删除/上移/下移/锁定等），当前图层面板仅有标题和对象列表，操作按钮分散在每一行。

## 附录：差距统计总览

| 维度 | LabelShop 规范项数 | 当前已实现 | 缺失 | 完成率 |
|------|-------------------|-----------|------|--------|
| 顶级菜单 | 12 | 12 | 0 | 100% |
| 菜单项（含子菜单） | ~110 | ~75 | ~35 | ~68% |
| 快捷键 | 30 | 0 | 30 | 0% |
| 右键菜单项 | ~40 | 0 | ~40 | 0% |
| 右键菜单场景 | 5（画布/对象/图层/标签页/打印面板） | 0 | 5 | 0% |
| 交互操作 | ~15 | ~6 | ~9 | ~40% |
| 主界面元素 | 12 | 11 | 1（版面旋转指示图标） | ~92% |

**核心结论**：MaxLabel 的菜单框架和界面布局已较好还原 LabelShop，但在**快捷键（0%）、右键菜单（0%）、精细交互（40%）** 三个维度存在显著差距。优先级最高的是补齐快捷键体系和画布右键菜单，这两项对操作效率影响最大且实现成本相对可控。
