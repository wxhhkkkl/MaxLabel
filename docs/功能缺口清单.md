## 三、已实现但有关键限制（容易被误判为完成）

1. **本地安装（2）**：安装/卸载可用，但**安装包没有许可协议页**——`build/license_zh_CN.txt` 缺失，`node scripts/installer-license.test.cjs` 实测失败；卸载默认保留 `%APPDATA%` 用户数据。
2. **打印机识别（6）**：无 OS 级协议自动识别，普通驱动打印机需手选指令集或按品牌推荐。
3. **表格（282）**：完整对象（行列/合并/边框/打印），但**单元格内不能放文字或条码对象**。
4. **纸张颜色（24）/ 形状孔洞（28）**：代码自述只用于编辑显示，不实际输出。
5. **打印预览**：代码对「打印机内置驱动」有「不支持打印预览」的禁用分支（`PrintDialog.tsx:151`、`messages.zh-CN.ts:137`），需真机确认是否符合预期。

## 五、复查方法

本次核对按「模型 → UI → 执行链路」三段展开，重点检查：

- `app/src/shared/domain/**`：对象、数据源、打印机、文档模型
- `app/src/renderer/src/dialogs/**`：属性、数据源、打印、选项对话框
- `app/src/renderer/src/editor/**`、`features/commands/**`：画布交互、菜单与快捷键
- `app/src/shared/print/**`、`app/src/main/printing/**`：指令生成与实际发送
- `app/src/main/db.ts`、`app/src/main/dongle/**`：数据库与加密狗
- `app/tests/**`：只作为链路证据，不单独作为「已实现」依据

已复核的关键结论：

- 加密狗：`app/src/main/index.ts:159` 调用 `createConfiguredReader({ packaged: app.isPackaged })`，未注入 `vendorRead`；`app/src/main/dongle/dongleReader.ts:167` 在打包分支直接走 `createVendorReader(options.vendorRead)` → 永远读不到。
- 激活：`app/src/main/entitlementService.ts` 全文不引用 `license.json`。
- 安装器：`node scripts/installer-license.test.cjs` 当前失败（缺 `build/license_zh_CN.txt`）。

> 建议每次发版前重跑：`npm run typecheck && npx vitest run`、`npx playwright test tests/e2e/start-page-entitlement.spec.ts`、`node scripts/installer-license.test.cjs`、`node scripts/installer-uninstall.test.cjs`。
